### Deviations from the design bible
1. **DCR — a sprite's tier is now data (docs/03 §1) and it gates path overrides.** The old resolver derived each
   sprite's earliest tier from whichever tables mentioned it, so a path tier list (T2/T3) silently promoted the
   T3-only faces 21/25/27/29/30 into stage 3. `casting.sprites[id].tiers` now carries the inventory's own range and
   only its minimum gates a *candidate* (path override or sibling); a gated candidate falls through to the feeling's
   base cell, never to the fallback face. Proposed doc text for docs/03 §3 step 3: "gates: sprite.min_tier <= tier
   (sprite.min_tier is the lowest tier in the docs/03 §1 inventory row; a gated path override falls through to
   BASE[tier][feeling])". Impact: YANDERE angry at stage 3 shows 17 instead of the knife, AWAKE cold/confused at
   stage 3 show 07/08; at stages 4–5 every tabulated override lands unchanged. No other path changes (TSUN's
   03/07/18/17 all start at T0), and base-table cells are deliberately not tier-gated because docs/03 §3.1 casts
   16 at T0 i3 (see follow-up 5).
2. **DCR — `budget: terminal climax only` scope (docs/10 §3).** Read as: sprite 30 may appear at T3 (docs/03 §3.1
   puts it at angry i3), but its `system` sting (`stinger.stage_change`) fires only at stage 5 and its fx degrades
   through the same row's `fx_below_stage5` — the existence of that field implies the entry set does fire below
   stage 5. The other documented budget, `1 reveal per scene` (sprite 21), gates the sprite itself and is
   scene-scoped (cleared by `reset_scene()`). Proposed: state which field the budget scopes in docs/10 §3.
3. **Motion amplitude numbers are art direction, not doc numbers.** docs/03 §4 gives one displacement per preset
   and no intensity ladder, so `casting.motion_intensity` = i1 ×0.6, i2 ×1.0 (the doc's own numbers), i3 ×1.4.
   Generated into docs/10 §2. No new art, no new colours.
4. **Corrupt-band siblings are art direction.** docs/10 §3.1 delegates T2+ siblings to the resolver's path rules but
   lists no pairs, so `casting.siblings_corrupt` ships 21→24, 22→26, 23→29, 24→28, 25→29, 26→28, 27→24, 28→26,
   29→23, 30→21 (same path signature / mood family, corruption band only, validated in build_casting.py). A swap to
   a sibling whose own tiers start above the current tier is skipped rather than jumping forward.
5. **Motion amplitude applies to displacement, not to idle breathing or freeze** — the `breathe` baseline and
   `freeze` are state, not emphasis. Reduced motion still cuts shakes/drifts outright (no softening).
