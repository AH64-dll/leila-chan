### Deviations from the design bible
- **rules.md +1 line:** `music, fx and cue: use only the values offered this turn.` — makes the docs/08 §5
  parenthetical "(cues/music/fx lists are whatever the schema allows this turn)" explicit for a 4B model.
  Everything else in rules.md is verbatim tested text.
- **glosses.md is a separate file** rather than inlined at the end of rules.md; docs/08 §5 shows them adjacent in
  the assembled prompt, which the layer order rules→glosses preserves. Lets SYS keep keys/files stable.
- **Few-shot format inside stage files:** `Player: <msg>` then `You: <compact one-line Turn JSON>`. Compact JSON
  (no inner whitespace) because these examples count toward the 900-token system prompt. The assistant side is
  full Turn JSON on purpose: docs/08 §1 stores real history as plain spoken text, so the few-shots are the
  model's only exemplar of the output shape and field order.
- "Sarah" is used as the fictional rival name in one example — the same name docs/08 §6 and the experiment CASES use.
