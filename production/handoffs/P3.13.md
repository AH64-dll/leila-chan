### Deviations from the design bible
- **Settings screen lives in the PauseMenu overlay, not a `ui/Settings.tscn`.** docs/07 §2's scene
  tree lists `ui/Settings.tscn`; P3.13's brief says "one entry point, don't ship two", and the Esc
  panic pause needs an overlay that survives `get_tree().paused` anyway. One autoload owns both —
  two scene files would have been the duplicate surface the brief forbids. If the producer wants a
  `Settings.tscn` scene file for the editor workflow, that's a mechanical follow-up (DCR-lite; the
  contract — one surface, Settings.gd as the only store — is already enforced by tests).
- **"Resources link" opens the player's browser** via `OS.shell_open` with the URL in `ui.json`
  (`https://findahelpline.com/`). docs/01 §4 requires the link; docs/05 §0 rule 2 forbids *game*
  network calls — a user-initiated browser open is the standard reading of the pair, but reviewers
  should confirm the intent. The night Esc behavioural change (pause no longer force-finishes the
  night) is a semantics fix required by rule 3 ("safe pause", not skip); the old test was updated.

### Summary
Round 2 closes both round-1 blockers and the cheap S3/S4 list. `full` is no longer reachable from the
calmer toggle: `Settings` remembers the explicit level the cap was covering

### Deviations from the design bible (round 2)
- **DCR (docs/05 §0 rule 2 wording).** Rule 2 says "No network calls, ever." The P3.13 resources link
  calls `OS.shell_open` on an explicit press, which hands the URL to the *player's* browser; `game/`
  opens no socket and makes no request. Proposed text: "…the Settings resources link may hand its URL
  to the player's browser on an explicit press; the game itself makes no request." Owner: producer/user
  (hard rule). Until then the behaviour stays as shipped and the code comment names the scope.
- **DCR-lite (docs/02 §8 unset level, DES-4).** docs/02 §8 names `calmer` and `full`; `""` is the
  *absence* of a choice and is the fail-closed state. Proposed: one sentence in §8 saying the settings
  menu's third state is the unset/fail-closed one and is never written by the calmer toggle.
- **Title / New Game Esc semantics (DES-3).** Title: Esc used to `quit_requested`; New Game: Esc used
  to go Back. Both now land on the safe pause (docs/05 §0 rule 3 — "Esc always opens a safe pause"),
  and Quit/Back are one click away on the pause page. Night's change from round 1 is the same rule.
