### Deviations from the design bible
- **Settings screen lives in the PauseMenu overlay, not a `ui/Settings.tscn`.** docs/07 §2's scene
  tree lists `ui/Settings.tscn`; P3.13's brief says "one entry point, don't ship two", and the Esc
  panic pause needs an overlay that survives `get_tree().paused` anyway. One autoload owns both —
  two scene files would have been the duplicate surface the brief forbids. If the producer wants a
  `Settings.tscn` scene file for the editor workflow, that's a mechanical follow-up (DCR-lite; the
  contract — one surface, Settings.gd as the only store — is already enforced by tests).
- **"Resources link" opens the player's browser** via `OS.shell_open` with the URL in `ui.json`
  (`https://findahelpline.com/`). docs/01 §4 requires the link; docs/05 §0 rule 2 forbids *game*
  network calls — a user-initiated browser open is the standard reading of the pair, but reviewers
  should confirm the intent. The night Esc behavioural change (pause no longer force-finishes the
  night) is a semantics fix required by rule 3 ("safe pause", not skip); the old test was updated.
