### Summary
The dose now changes between turns with no reload. `LeilaLLM.set_control_vectors` caches unit vectors and mixes them, and
`NativeBackend` binds `TurnRequest.dose` before every generate. The M39 spike is real on the native backend: T02, T14 and
T18 arm it from stage 3, it decays 3.5 then 1.75, a glitch marks the start and a prompt line lets her notice afterwards. It
stays off on the server transport, whose dose is a launch flag. No `Director.gd` change: the hook is in `InputHook`.

### The blind read, criterion 3
`experiments/steering/mix_native_v1/README.md` has every number. Criteria were fixed before generation and judges were blind.
- Engine correctness: byte-identical to the pinned server's `--control-vector-scaled`, 10/10 at temperature 0.
- AWAKE at stage 5 (malice 8 + aware 0.5): judged aware 10/10 against 4/20 for malice alone. The judge marked 4/10 gibberish.
- YANDERE at stage 5 (malice 8 + possessive 0.5): **fails**. Judged possessive 1/10 and 2/10 on two decks. Malice alone
  scores the same pooled, 3/20 each. The vector adds no measurable signal here.
- Limits: n is small, this judge is weak on possessive (0.5 alone scored 3/10, P3.03's judge 7/10), and there is no path
  prompt module in this test. In the game the prompts carry much of YANDERE. This is not a runtime defect, and would behave the
  same on the server. No dose value was changed. The user decides under D42.
