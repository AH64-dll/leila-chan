# Handoff: P4.04 NativeBackend behind the facade, backend switch, parity

## Round 1  (2026-11-05, agent: haiku-worker)

### Summary
The game now runs on the in-process engine by setting one switch. `LEILA_BACKEND=native` selects it, and an exported build uses it by
default. Replies on the prompt lab are byte-identical to the pinned server, 128/128. The safety classifier now has a native
transport on its own unsteered context, also byte-identical to the server, on the real corpus, 41/41.

That corpus run also showed a separate problem that was already there: **the real model answers "no" to 16 of 31 flagged harmful
requests, and 14 of those lines display at stage 0.** Decision D43, risk R16. It is the same on the server. No filter data changed.

### The classifier
Control vectors belong to a context, so a second context on the same model is dose 0 by construction (docs/02 §8).
- Proof (`native/tests/classify_check.gd`): a 33-word answer is byte-identical under malice x12, while the main context changes. While a
  free-running turn generated, 14 classifier calls returned, every one correct, and the turn's text did not change.
- Cost: 144-152 MiB of VRAM at n_ctx 512, n_ubatch 64, down from 604 MiB at 1024/512 (`classify_vram.gd`). Worst later classify 125 ms against
  the 900 ms hold.

### Decisions the reader may want to overturn
- The parity criterion is judged with a shared seed, since without one a single reply moves a stage's score past the tolerance. The README
  has the reasoning. Stochastic runs were not repeated, because identical replies leave nothing for them to add.
- The switch is an environment variable, with no player setting. The row says "settings/dev" and the player has no reason to choose.
  A dev run still defaults to the server transport.
- `native` with the extension missing warns and falls back to the server. P4.08 owns the player-facing error.
- The model loads on the first turn, not at boot, until P4.08 adds the loading screen.

### Known limits
- `metrics.dose_error` is still only visible in metrics, with no log line. P4.09's regression run should surface it.
- The shim's SIGINT stop is not a clean unload (exit -2). It is a dev tool and the OS frees the GPU memory.
- `classify_parity.py` is 175 lines against a 150-line brief limit. Not trimmed, because it produced the evidence.
