### Summary
The docs/05 §1.4–§1.5 meta events that leave the text box now exist. `game/llm/meta/MetaEventsM31.gd` is mounted
by `MetaDirector._mount_effects()` (the file path is the registration seam) and owns detection + effects for
M31–M38: it reports one scripted event per `poll_scripted(stage)` call and the host charges the docs/05 §3
budget exactly as for an offered action, then calls `fire(id, action)` back. All bytes and paths live in
`MetaNotesStore` — the only disk writer — which refuses any root outside `user://` and any path that climbs,
carries a scheme, or is absolute (fail closed, never normalised). The Extras reader (`MetaNotesPanel.gd`, plus
the section `build_extras_section()` adds to `Extras.gd`) shows every note in-game, which is also the documented
fallback when the folder is read-only. Content is `game/data/meta_notes.json`; the clock is an injectable
`Callable` returning unix seconds, so no test depends on the wall clock.

### Per-event coverage (docs/05 §1.4–§1.5)
- **M31 letter** — offered `write_note` (the `meta_events.json` row shipped in P3.08, unchanged); `fire` writes
  `user://letters/for_<name>.txt` from her scanned say, in-memory fallback + Extras button if unwritable.
- **M32 diary** — `inner` buffered per day, scanned/deduped/capped, written to `user://diary/day_NN.txt` on the
  `day_changed` boundary; the event announcing it is charged by the host next scene.
- **M33 save names** — `user://saves/meta_names.json` ledger beside the slots; seeded names per stage/day.
- **M34 other player** — St 4 + AWAKE + day ≥ 3 + not seen: a `fiction: true` ledger row, never a loadable save.
- **M35 real clock** — ambient (`budget: false`) greeting note once per scene; `apply_sky()` tints `Date.gd`'s
  background by bucket, skipped under `Settings.photosensitive`.
- **M36 3 AM** — inside 02:00–04:00 once per night (`meta_three_am_night` flag): night line, instability +3,
  `music_box` request.
- **M37 birthday** — `MetaBirthday.parse()` reads Memory facts through the data-driven grammar (month names,
  dmy/mdy/iso orders; numeric `03/05` deliberately unsupported); fires once on that real date
  (`meta_birthday_seen` flag).
- **M38 long session** — session clock (`begin_session`) ≥ 7200 s, once per session.

### Deviations from the design bible
None that contradict the docs. Choices the docs leave open:
- **Scripted events ride `turn_events()`, not `GameState.queue_event()`.** A scripted event fires while the turn's
  context is assembled; the pending queue drained one step earlier, so queuing would deliver the EVENT line one
  turn late (the P3.08-r1 OPPORTUNITY bug, same shape). Same-turn delivery is the documented "she is told
  afterwards" at the earliest possible moment.
- **M35's clock greeting is ambient (`{"budget": false}`).** docs/05 §3's caps count fourth-wall beats; the clock
  line is context like a T-row line, and spending the St-3 scene slot on it would starve every date's one event.
  It still lands in the ledger, the session log and F3 (`ambient: true` marker).
- **The M33/M34 ledger is a file beside the slots, not a save slot.** A save file is SaveSystem's; `fiction: true`
  marks the M34 row so the Extras reader can label it and nothing can load it.
- **`03/05`-style numeric birthdays are unsupported** (day-month vs month-day is unresolvable without a locale);
  a wrong birthday is worse than none.
