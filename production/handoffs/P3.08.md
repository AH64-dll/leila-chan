### Deviations from the design bible
None that change behaviour. Three implementation choices the docs do not spell out as data:
- **New data keys.** docs/05 §0 states the rules but not how they are encoded; `meta_events.json` rows carry
  `fallback` (§0.5 "every effect has an accessibility fallback") and `writes` (§0.1 "never outside `user://`").
  `tests/test_meta_events.py` pins both, so the shipped catalogue cannot drift.
- **The scene cap counts open offers too.** docs/05 §3 says "max 1 meta event per scene at stage 3, 2 at 4, 3
  at 5"; because 0–2 actions can be offered *and taken* in the same turn, the cap would otherwise be exceedable.
  Counting open offers makes it stricter, never laxer.
- **`once_per_save` lives in `GameState.flags["meta_seen"]`**, which doubles as the Extras list docs/05 §3
  requires — no second ledger to keep in sync.

### Deviations + decisions (round 2)
- **M01 is charged against the per-scene budget, and a spent scene is not intercepted.** docs/05 §1.1 makes
  `refuse_exit` the request-opened offer; docs/05 §3 caps meta events per scene. CODE-4/SAF-3 asked for the cap
  to hold at execution, so the close request is capped too — and when the scene has no room the press simply
  closes. That is the only ordering that never weakens docs/05 §0 rule 3; the alternative (exempt M01) would let
  a stage-3 scene run two meta events. No DCR: the docs never say M01 is exempt.
- **The §0 effect class table is code, not data** (`ACTION_CLASS`). docs/07 §2 puts *content* in data; a safety
  class a data edit can rewrite is the hole SAF-1 described. The data keeps its `immersion_deep` marker and the
  Python contract pins it to the table, so the catalogue still reads like docs/05 §1.2.
- **The scheduler's floor is derived from the row gates** (no data key). docs/05 §1 gives per-event gates and §3
  gives no global floor, so the rows are the only authority the doc states.
- **The row vocabulary is closed.** Unknown effect keys are `R0`; docs/05 §0 names the forbidden behaviours, and a
  closed vocabulary is how "no network, ever" stops depending on a row volunteering the key.
- **docs/05 §1.4's M31 St 2 gate is now live**, so a letter can be offered from stage 2. That is the documented
  gate; round 1's `scheduler_stage_min: 3` was the bug.
