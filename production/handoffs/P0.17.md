# Handoff — P0.17: smoke.py check_turn TypeError on unhashable feeling → clean TURN INVALID

## Round 1  (2026-11-02, agent: swe2)

### Summary
`check_turn` in `tools/llm/smoke.py` no longer crashes on unhashable `feeling` values. `FEELINGS`
is a dict, so `x not in FEELINGS` hashes `x` — a JSON list/object feeling raised
`TypeError: unhashable type` instead of producing a clean `TURN INVALID` + exit 1. The check now
requires `isinstance(str)` before the dict-membership test (same guard pattern as the adjacent
`intensity` check, and faithful to the schema's `"type": "string", "enum": …`). A committed
regression test drives `smoke.py` end-to-end against a stub llama-server; CI runs it via `pytest`.
