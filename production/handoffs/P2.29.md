# Handoff — P2.29: P2 gate-r1 carry-over batch (QA harness)

## Round 1  (2026-11-05, agent: gemini-3.8-flash)

### Summary
Addressed the four QA harness carry-over items from `production/gates/P2-gate-r1.md` §5. The full-run harness now supports `--own-server` (and `LEILA_OWN_SERVER=1`) which configures `auto_start: true` on the backend, launches and supervises its own llama-server per dose schedule, connects to `LLM.steering_applied` to log relaunch outcomes, and eliminates attach-mode `server_not_owned` refusals. The transcript renderer now dedupes rendered days and turns on `--resume`, continuing day sections without duplicate `## Day N` headers, appending only the tail of unrendered turns, and emitting `## Checkpoint summary` (with optional `--checkpoint-days=N`) for intermediate segment stops rather than full run summaries. Four `end_date` offered-action cases were added to P3 path sets (`stage_3_paths.jsonl` SPLIT/TSUN and `stage_4_paths.jsonl` HOLLOW/ANCHOR) satisfying `lab.load_set()` requirements. Finally, `Director._start_turn` now detects dropped prompt layers from `PromptBuilder.build()` and pushes a warning naming them (`push_warning("Director: dropped prompt layers: ...")`) while exposing `Director.last_missing_layers`, keeping `Director.gd` strictly under the 1000-line gdlint limit.

- `game/autoload/Director.gd` — surfaces `debug.missing` from `PromptBuilder.build()` as `push_warning("Director: dropped prompt layers: %s" % ...)` and exposes `last_missing_layers`; line count 998 (< 1000 max).
- `game/tests/DirectorRoutingTest.gd` — added `test_dropped_prompt_layers_surface_in_director_warnings`.
- `game/tools/full_run_driver.gd` — adds `--own-server` and `checkpoint-days` argument parsing; configures `auto_start: true` when own-server is requested; hooks `LLM.steering_applied` to log relaunch status in transitions; uses `FullRunStore.scan_rendered` to dedupe rendered turns, continue day sections, and emit checkpoint summaries.
- `game/tools/full_run_report.gd` — renders own-server dose binding and transition relaunch status in markdown; supports `is_checkpoint` parameter in `summary_lines()` to render `## Checkpoint summary`.
- `game/tools/full_run_store.gd` — added `scan_rendered(prefix)` to parse existing transcripts for rendered days and turns and convert prior segment-stop summaries to checkpoint summaries; added `build_payload()` / `final_state()` / `meters_dict()` helpers.
- `game/tests/FullRunHarnessTest.gd` (new) — tests for own-server mode, transition relaunch rendering, checkpoint vs run summary rendering, and resume deduplication.
- `tools/promptlab/sets/stage_3_paths.jsonl` — added SPLIT and TSUN stage 3 `end_date` offered cases with OPPORTUNITY and action-naming lines.
- `tools/promptlab/sets/stage_4_paths.jsonl` — added HOLLOW and ANCHOR stage 4 `end_date` offered cases with OPPORTUNITY and action-naming lines.
- `tools/promptlab/sets/README.md` — updated case counts and notes for P3 path sets.
