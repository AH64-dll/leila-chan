### Deviations from the design bible
1. **DCR — anti-repeat sibling table is underdocumented (docs/03 §3 step 4).** The doc names one
   example (`06 → 01`) but the resolver needs a mapping for all 22 feelings. I generated
   `casting.siblings` (`tools/casting/build_casting.py:194`, validated at `:267`–`:275`) and listed it in
   `docs/10_CASTING.md` §3.1. **Proposed doc text (docs/03 §3 step 4):** "The sibling table lives in
   `casting.json` (`siblings[f]`, generated by `tools/casting/build_casting.py`). Siblings are healthy
   faces (ids 01–20) in the same mood family; a swap never crosses the healthy/corrupt band. T2–T3
   path-aware siblings belong to the path rules (P2.14)." Impact: documentation only once accepted;
   no code change. The producer decides.
2. **Camera preset geometry (docs/07 §3.3 names the presets only).** Chosen: `full` = the 384×688 frame;
   `knees` = a 262×470 band (x 61–323, so ~1.46× larger than full); `bust` = the sprite's authored
   `bust_crop_native`; `face` = a 150×170 box on the `eyes_native` midpoint + 24 px. Fitting is min-scale
   and the view is clamped inside the frame (`Character.gd:235`). Reviewable in the four stills.
3. **Fractional camera zoom.** The presets min-fit their rects (1.46×, 2.18×, 2.56×), so crop framing does
   not land on an integer pixel grid; the *base* presentation is pixel-perfect (x2 art at 0.5, nearest,
   integer window stretch). If design wants integer-only crop zoom, the presets need a different geometry.
4. **`glitch` preset is scaffolded, not shimmed.** docs/03 §4 defines it as the glitch shader; this task
   emits the same 1-frame offset as `twitch` and fires `twitch_fired` so P1.11 can attach the chromatic
   split. The `desaturate` preset (HOLLOW / stage 5) is likewise P2.15 shader work; `casting.json` does not
   emit either name at T0–T2, and a test now fails if a future table emits a preset the scene lacks.
5. **Reduced motion is an API, not a Settings binding.** `Settings` is still a stub (P1.12/13 owns the
   real settings). `Character.set_reduced_motion(bool)` is the seam; the Date scene should bind
   `Settings` to it when both exist.
6. **`SpriteResolver` emits a beat packet, not just a sprite.** `resolve_beat()` returns sprite, motion,
   tint, valence, fx/cues/music pools, on-enter effects and the i3 camera push, and emits
   `beat_resolved`. This is the director-facing shape docs/10 describes; no table was forked into code.
