### Deviations from the design bible
1. **No `production/briefs/P3.19-r1.md` exists** (checked main tree, all
   worktrees, git history). The contract used is the phase row
   `production/phases/P3_paths_meta.md:42`: "Prompt lab v3: all 6 paths ×
   stages; path-separation metric (blind judge names the path from a
   transcript)" with acceptance "Validity/intent/fit thresholds hold for all
   paths; path separation ≥ 70 % per path". If a brief was intended, the
   producer should drop it in and reconcile.
2. **Path separation FAILS the ≥ 70 %/path gate** (58.2 % overall; 4 of 6
   paths below). Evidence says this is NOT a dose problem — the dose-0 P3.05
   control scores 49 % — and judge-prompt enrichment (signature-move
   definitions) and say-only transcripts both plateau at ~56 % on a sample, so
   the 4B judge's ceiling on this task is roughly coin-flip-plus. Two readings,
   both needing a decision:
   - *Paths are genuinely hard to tell apart at single-turn transcripts.* The
     path modules share register (all six are "hurt/obsessive-adjacent"), and
     the confusion matrix shows systematic merges: ANCHOR→TSUN (17) and
     ANCHOR→SPLIT (13) — ANCHOR's "ask for rules, come back when you slip"
     reads as TSUN denial or SPLIT testing to a blind reader; SPLIT↔TSUN merge
     both ways. P3.05's signature-move evidence shows the *moves* appear, but
     a single turn rarely carries enough of them.
   - *The judge is too weak.* P3.03 measured the same bare 4B at 44 % on
     authored trait text — below chance-plus on a 6-way task is within its
     noise floor. A stronger judge (or a two-stage "describe-then-classify"
     judge) was not tried; no bigger local model exists in `models/`.
   **DCR candidate:** either (a) sharpen the four new path modules' first lines
   so their signature moves land in turn 1 (NAR), or (b) re-spec the metric —
   e.g. judge on a *pair* of transcripts from the same path, or accept a
   stronger judge model — the phase row's "≥ 70 % per path" cannot be evaluated
   honestly with the current judge ceiling. Recommend a follow-up task:
   "Path separation: judge upgrade or module sharpening" (role: QA design +
   NAR), gated on a producer decision between (a) and (b).
3. **Sweep stays scalar-malice by design.** The six-path dose probe measures
   JSON validity vs dose only; the 0.1–0.5 path band is exercised in the
   path_matrix cells at real `dose.json` maps. Documented in plan.json's doc
   and sets/README.md.
4. **Cell sizes are uneven** in path_matrix (3–24 cases per cell; smallest:
   stage-5 SPLIT/TSUN/HOLLOW/ANCHOR = 3 cases × 2 runs). The ≥70 % gate on 6
   judged transcripts is noise-dominated for those cells — flagged, not
   hidden; the confusion table shows the aggregate.
