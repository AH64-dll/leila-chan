### Deviations from the design bible
None that contradict docs — but several deliberate choices where docs/07 §2 is silent (all provisional, cheap to change):

1. **Viewport/window:** doc is silent. Set `viewport 384×688` (native sprite size, `art/leila/README`), stretch
   `canvas_items` + `scale_mode="integer"`, window override `768×1376` — i.e. ×2 portrait ≈9:16, so the full-body
   sprite maps 1:1 and scaling stays pixel-perfect on resize. ART should confirm at P0.08/P1 (a landscape VN layout
   would change `viewport_*` + stretch, nothing else).
2. **Renderer `gl_compatibility`:** docs/07 §1 requires desktop + Android + iOS from one project and the game is 2D
   pixel art — Compatibility covers all three; Forward+ would block mobile.
3. **`textures/canvas_textures/default_texture_filter=0` (Nearest)** project-wide, per `art/leila/README`
   ("Filter: Nearest, scale ×2 or any integer"). P0.08 still sets per-import settings.
4. **Autoload order** = doc order (GameState … Settings). Init-order semantics come when the stubs get bodies.
5. **No `.gdignore` inside `game/`** — everything under `game/` is intended project content; a `.gdignore` dir is
   excluded from exports, which would be wrong for `data/` and `assets/`. The "root images" criterion is met by the
   project living under `game/` (decision D6), verified above.
6. **`tools/godot.sh/.ps1` launchers**: `godot` isn't on PATH on this machine; the scripts read `game/.godot-version`
   and exec the local binary (`LEILA_GODOT` overrides). Reviewers with `godot` on PATH can run the criterion command
   verbatim.
7. `boot_splash/bg_color` set to black (horror-appropriate, zero-cost). M17's
   `per_pixel_transparency`/`transparent_bg` deliberately left unset — that's MetaDirector's task.
