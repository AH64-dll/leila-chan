### Deviations from the design bible
- **DCR applied (DES-2/D21, flagged in the P3.03 review):** docs/06 §3's `path_mix`
  1.0–5.0 band was entirely inside the incoherent range — P3.03 measured gibberish at
  ≥1.0 and legible steering only ≤0.5. The table now reads `path weight` 0–0.5 with an
  explanatory note; `paths.json`'s `scale_convention` records the same.
- **path_mix retuned to 0.1/0.2 (was 1.0–5.0 placeholder).** It binds no file today
  (declared `unbound`, logged on relaunch), so the number is forward-looking: it is the
  weight the eventual bound path slot would carry pre-assignment.
- **`mods.player_slider` floor −1** (docs/06 §3 already allowed the slider to push
  below zero; the data now pins it): lets the player pull a keep vector negative as an
  "ANCHOR-like" correction at high doses — recorded in dose.json `mods.doc`.
