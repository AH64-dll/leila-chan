# Handoff — P1.18: Transcript logger: prompt, schema, raw output, applied events per turn → user://debug (dev builds only) + replay loader stub

## Round 1 (2026-11-03, agent: gemini-3.8-flash)

### Summary
Wired `TranscriptLogger` into `Director.gd` (`Director.transcript_logger`) so that every completed, failed, and cancelled turn logs canonical turn record `{prompt, schema, raw output, applied events, metrics, stage, path, dose, day, meta}` to `user://debug/` JSONL via `TranscriptLogger`.
Added `LLM.get_backend()` and `LLM.last_metrics()` to pass transport timing metrics from `LlamaServerBackend` (or mock backend) into the transcript records.
Connected a safety redaction Callable hook (`Director._redact_record`) that applies `Safety.redact_record()` when available and `filter_output()` as fallback, ensuring unredacted model outputs never touch disk.
Implemented `Director.replay_turn(turn_record: Dictionary) -> bool` to re-feed transcripts back through `IncrementalJson`, dispatching events to subsystems (`AudioDirector`, `FX`, `SpriteResolver`/`Character`, `ChatUI`) and updating `GameState`. Added comprehensive end-to-end integration tests in `DirectorTest.gd`.
