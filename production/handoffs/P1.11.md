# Handoff — P1.11: FX v1: blush_glow, hearts, sparkle, shake_small, zoom_face with per-effect cooldowns

## Round 1 (2026-11-03, agent: gemini-3.8-flash)

### Summary
Screen effects v1 is implemented across the `FX` autoload and the `Character` scene host. `FX.gd` reads effect rules (`gate`, `cooldown_turns`, `max_per`) from `casting.json["fx"]` (generated by `tools/casting/build_casting.py` and documented in `docs/10_CASTING.md`), tracks turn counts, enforces the 3-turn cooldown and the 2-turn window cap (`shake_big` / `glitch`), drops invalid/unimplemented/over-budget requests silently, and provides an F6 debug menu (`FxMenu.gd`/`FxMenu.tscn`). `Character.gd` implements the five Stage 0 visuals (`blush_glow`, `hearts`, `sparkle`, `shake_small`, `zoom_face`) in the project pixel-art palette, respects reduced motion by cutting shakes and particle drifts, and wires the `twitch_fired` signal to a 1–2 frame chromatic split shader (`glitch_split.gdshader`).
