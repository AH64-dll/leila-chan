# Handoff — P1.01: `LLM.gd` facade — TurnRequest/TurnStream types, worker thread, main-thread signals via call_deferred, cancel

## Round 1  (2026-11-02, agent: swe2)

### Summary
The LLM facade now exists for real: `LLM.generate(TurnRequest) -> TurnStream` spawns one worker
thread per turn, runs an injected `LLMBackend` transport on it, and relays every emission to the
main thread via `call_deferred`. `TurnRequest` carries exactly the docs/07 §3.1 fields
(`messages`, `schema`, `sampling`, `dose`, `max_tokens`); `TurnStream` exposes `token` /
`completed` / `cancelled` / `failed` signals plus `cancel()`. One turn at a time; a second
`generate()` while busy fails with `{"code":"busy"}`. `set_dose()` stores the steering dose and
fills `request.dose` when a request leaves it empty. Eleven gdUnit4 tests drive a scripted
`FakeLLMBackend` through stream, cancel, error, busy, dose-fill and main-thread non-blocking
paths — all green, plus lint/format clean.

### Deviations from the design bible
None that contradict it — §3.1 is a sketch and left these to me:

- **TurnStream's signal set** is the concrete contract the doc doesn't spell out: `token(text)`,
  `completed(full_text)`, `cancelled()`, `failed(error)` with exactly one terminal emission.
- **`set_dose` semantics**: stored as the facade's current dose, frozen into `request.dose` at
  `generate()` only when the request leaves it empty (explicit per-request dose wins).
  Whether `set_dose` should also push to a live backend (server restart per docs/06 §4) is
  P1.02/P2.03's call — see follow-ups.
- **Busy policy**: while a turn is in flight, `generate()` returns a stream that fails with
  `{"code":"busy"}` rather than queueing or superseding — the doc is silent; single-context
  serving makes concurrent turns impossible anyway.

### Open questions / follow-ups
- **P1.02**: `LlamaServerBackend` implements the `LLMBackend` contract (on_token per chunk,
  prompt return on `cancel.is_cancelled()`, `{ok,text}`/`{ok,error:{code,message}}` result) and
  wires itself as the autoload's default backend.
- **P2.03**: decide whether `set_dose()` while idle should also notify the backend (server needs
  a restart to change the launch-flag dose; native can apply per turn) — the seam is
  `LLM.set_backend`/`set_dose`.
- **P1.08 (Director)**: the `busy` failure is surfaced to the caller; if player input should
  supersede a running turn instead, that policy lives in Director, not here.
- **Latency logging** (ttft / first `say` / full turn — role checklist) lands with the real
  transport in P1.02; the facade keeps no timers of its own.
- `TurnRequest.to_dict()` exists so the P1.18 transcript logger can serialize requests directly.
