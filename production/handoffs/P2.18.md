### Deviations from the design bible
1. **Backgrounds and ambience beds that do not exist yet.** The dates reference `bg/classroom`, `bg/park`,
   `bg/street_rain`, `bg/rooftop`, `bg/her_room` and `ambience: "none"` (D01 uses the shipped
   `ambience.paper`). `assets/bg/` only has `cafe.png` today; `Date.load_scenario()` skips a missing
   background, and an unknown ambience key is denied by `AudioDirector.play_system`, so a scene runs with
   no background/bed rather than failing. docs/08 §7 already uses `bg/street_rain` in its own example, so
   the names are the documented ones — the assets are ART/AUD work, listed as follow-ups below.
2. **I01's `background`/`music` are a placeholder.** The schema requires both for every scenario, but an
   interrupt runs inside a parent date. It ships `bg/cafe` + `calm`; the day/night runner (P2.19) should
   keep the parent scene's background and music when it injects an interrupt. Follow-up, not a doc change.
3. **I01's end rule.** docs are silent on the end action of an interrupt; it uses the docs/08 §7 example's
   `on_goal: "end_date"` with tight bounds (min 3 / max 6) so the turn bound always ends it. The action is
   only reachable if `offered_actions` ever includes it, and nothing offers it today.
4. **Budget convention.** The ≤ 900 line is measured on the fixed layers with the scene empty, and the
   scene block has its own 150 line (docs/07 §3.1 budgets them separately; P2.13 shipped with the same
   reading). Measured maxima here: fixed **868**, scene **119** (129 on an event turn, counted once).
5. **Disorder scan: acronyms case-insensitive, one exception.** `tests/test_scenarios.py` matches
   `bpd`/`npd`/`ocd`/`ptsd` as whole words in **any** case — they are not English words, so lowering the
   text is safe — and matches the long forms anywhere, case-insensitively. Only `did` needs the uppercase
   rule: lowercase "did" is ordinary English ("he did not"), so it counts as the disorder only as the
   written acronym `DID`. A negative-control test (`test_disorder_scan_catches_every_case`) proves each
   acronym is caught in mixed case and that "did" is not (round-2 CON-1).
