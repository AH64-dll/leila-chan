### Deviations from the design bible
1. **DCR — Window override 1080p sizing (Gate C5, docs/07 §2):**
   - *Where:* `game/project.godot` (`window_width_override`, `window_height_override`); `docs/07_TECH_ARCHITECTURE.md` §2.
   - *Problem:* docs/07 provisional window override `768×1376` exceeds standard 1080p desktop height (1376 > 1080).
   - *Change:* Set default window override in `project.godot` to native 1× `384×688`. Godot's `scale_mode="integer"` and `aspect="keep"` automatically integer-scale the viewport to 2× ($768 \times 1376$) or 3× when maximized or running on 1440p/4K displays without breaking pixel grid alignment.
   - *Impact:* Game launches cleanly inside any 1080p monitor without clipping beneath taskbars.
2. **DCR — FX shader delegation to P1.11 (docs/03 §4, docs/07 §3.3):**
   - *Where:* `game/scenes/DateFX.gd`, `game/scenes/Date.gd:play_fx()`.
   - *Problem:* docs/03 describes `twitch` as 1-frame offset + chromatic split and `sparkle` as shader effects; P1.16 is scene assembly and café art, while P1.11 owns screen-effect shaders and shader profiling.
   - *Change:* `DateFX.gd` provides screen-space overlay approximations (warm blush tint, dim twitch flash, heart burst, camera shake), safely handling `twitch`, `blush_glow`, `hearts`, `shake_small`, and `sparkle`. P1.11 replaces overlay stubs with Godot shader materials.
   - *Impact:* Clean sequencing without blocking date assembly on shader asset development.
3. **DCR — Ambience room tone key `amb.cafe`:**
   - *Where:* `game/scenes/Date.gd:load_scenario()`, `D02_cafe.json:7`.
   - *Problem:* `D02_cafe.json` specifies `"ambience": "cafe"`, but audio rules only configure `"amb.rain"`.
   - *Change:* `Date.gd` dispatches `AudioDirector.play_system(&"amb.cafe")`, which safely no-ops until audio assets are imported in Phase 1/Phase 2 audio tasks.
