### Deviations from the design bible
1. **DCR-1 — few-shot placement (docs/08 §3 and §4 vs docs/07 §3.1’s 900-token system budget).** docs/08 §3 asks
   for 2 examples in *each* stage file and §4 says the full path files add examples; at 4 examples the stage × path
   assembly measures ~1100 tokens, which cannot fit the budget (the base persona+player+rules+glosses alone is
   ~600). Each assembly therefore ships **exactly 2** exchanges, one in the stage file (the stage’s signature beat:
   leak→correction, cold→pleading, the closed window, the running program) and one in the path file (the trait), and
   `tests/test_prompts.py::test_every_stage_path_assembly_carries_two_fewshots` enforces the pair. Proposed doc
   change: docs/08 §3 last paragraph → “Each assembly shows 2 example exchanges: the stage file carries one, the path
   file carries one (per path at stage ≥ 3).”
2. **stage_3 wording (docs/08 §3).** `{path} has taken hold of you` becomes “Your path has taken hold of you.” —
   PromptBuilder substitutes only `{player_name}`, so a literal `{path}` would reach the model (and the placeholder
   test forbids any other token).
3. **LF + no blank lines in the prompt files.** P1.05 shipped persona/rules/glosses/stage_1 with CRLF; the CRLF
   both inflated the builder’s character-based estimate (~12 tokens) and hid `test_system_layers_follow_docs08_order_without_gaps`’
   `\n\n` assertion. Text is unchanged (line endings + one intentional blank line before the examples); the golden
   fixtures were regenerated with `game/tests/tools/prompt_builder_goldens.gd` (the intended path for a prompt change).
4. **No brand line yet.** docs/09 §3 permits “I’m a Qwen model” as the AWAKE factual line but requires a legal read
   first; the shipped modules say “language model” and stay brand-free (the brand test now also covers
   `path_AWAKE.md` and `awake_system_prompt.txt`).
5. **AWAKE identity conflict resolved in-fiction.** persona.md forbids calling herself an AI “unless your stage
   allows it”; without an explicit permission a live stage-3 turn answered “maybe… I feel like a real person”.
   `path_AWAKE.md` now states the permission (“Say what you are.”) and the live re-run names the model.
