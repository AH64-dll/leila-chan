### Deviations from the design bible

1. **`ChatUI.tscn` composite (docs/07 §2 lists the four components separately):** added as the
   wiring/assembly point for the turn loop and keyboard play; the four documented scenes exist
   unchanged inside it. Justification: "keyboard-only play works" and the streamed-turn loop need a
   concrete owner; P1.16's Date scene gets a one-line instantiation instead of bespoke wiring.
2. **Safety wiring is an injection point, not a direct autoload call (docs/07 §3.4, docs/02 §8):**
   `Safety.gd` is a stub (P1.19 in flight), so `ChatUI.say_chunk` pipes every chunk through the
   injectable `text_filter` Callable (default pass-through). The integration task must set it to
   `Safety.scan` (or the full pipeline `Safety.scan → PronounFix → Corruption.filter`) when wiring
   the Director — the UI-side hook and its test already exist. If this is judged unsafe rather than
   preparatory, file it back as rework.
3. **Chat log stores spoken text only at full display** (doc silent): a beat enters the log when
   `beat_displayed` fires, so cancelled/failed turns leave no ghost lines — matches "the log is the
   record of what was actually said" needed by M23/M24 later.
4. **Typewriter punctuation dwell (doc silent):** reads dwell briefly on `. , ! ? … — ; :` (ms values
   in `ui.json`) — standard VN feel; all values tunable in data.
