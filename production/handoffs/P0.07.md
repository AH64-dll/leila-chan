### Deviations from the design bible
docs/07 §6 describes CI scope ("no GPU needed" is the task title) but is silent on details;
additions only, no contradictions:

1. Repo-root `tests/` + `pytest.ini` — docs/07 §2 covers `res://` only; Python tests had no home.
   `testpaths = tests production` pre-wires the location P0.11 will likely use
   (`production/tests/`) so bare `pytest` keeps collecting both roots.
2. `tools/test.sh` exec bit — belonged to P0.15's carry-over list (CODE-1) but CI is blocked
   without it; done here early, P0.15 only needs to verify.
3. `gdlint game/` appears twice in the pipeline — explicit step for fast-fail lint before the
   ~50 MB Godot download, and again inside `tools/test.sh` stage 1. Intentional.
4. `gdformat --check` deliberately **not** a gate — that evaluation is P0.15's scope.
5. Runner pinned `ubuntu-24.04` (ubuntu-latest migrates to Ubuntu 26 per runner-images #14748);
   actions pinned `checkout@v7`, `setup-python@v7`, `upload-artifact@v7`; Python 3.12 (README pin).
6. Single `checks` job rather than 4 parallel jobs — total runtime ~30s; splitting would only
   re-pay checkout/setup cost for no benefit. JUnit upload only `if: failure()`.
7. Outward-facing note: pushing the branch + PRs was required by the acceptance criteria;
   executed minimally (no merge, no tags, demo branch + PR #7 deleted/closed after the red run).
