### Deviations from the design bible
- docs/02 §7 "through the glitch filter": no dedicated text-glitch filter exists in the codebase (no `Corruption` autoload). Implemented as: partial `say` shown verbatim-with-ellipsis + `fx: "glitch"` at stage ≥ 3 (the only stage gate where `glitch` is an allowed fx) + safety `filter_output` still applied — the §8 filter is never bypassed.
- docs/02 §7 "typing indicator stuck for 3 s": simplified — the "…" beat is emitted and the turn closes immediately; a 3 s stall needs UI scheduling that a turn-close fallback can't express without blocking the pipeline. The scary-silence intent is preserved; the literal 3-second stall is not implemented.
- docs/02 §7 "same 4-gram ×3" for repetition loops: implemented as a repeated unit of ≥ 4 tokens ×3 (a strict 4-gram misses "I love you so much" — a 5-token unit — and would also leave the kept text a fragment of the loop). Longest unit wins at a given offset so the whole first repetition is kept. Strictly wider than the spec's letter, matching its intent.
- Stage < 3 empty-say after the retry already failed also gets the "…" beat (spec only defines it for stage ≥ 3); the alternative is completing a turn with no visible reply at all.

### Deviations from the design bible
Round-1 deviations 1–4 stand (see above). Two additions this round:

- docs/02 §7 pronoun row: the row says "rewrite to You / `{player_name}`", but a bare `He`/`Him` rewrite has no grammatical second-person form to fall back on. Implemented as: `He's`/`His` are always rewritten (with `He's been/got` → `You've`, other `He's` → `You're`); bare `He`/`Him` are rewritten **only when the following verb can be safely re-conjugated** (or already agrees), otherwise the sentence is left intact and a warning is logged. This satisfies the row's intent (stop her talking about you in third person) without pushing grammar-broken text, per the DES-2 review direction.
- docs/02 §7 pronoun row, referent source: the doc names the condition but not where the other male referents come from. Implemented as a data list (`game/data/fallbacks.json` → `male_referent_names`, 27 entries: family nouns + male given names) checked against the say and the last three player messages. The list is data, so the scenario/design pass can extend it without touching code.
