## Round 1  (2026-11-02, agent: swe2)

### Summary
`production/tests/test_track.py` adds 51 pytest cases for the tracker: plan parsing, `fill`,
the TRANSITIONS table, `validate` (clean/warn/strict/every error kind), `set` state transitions
(deps, handoff gate, review-round gating, reopen, escalation), `review`, and `brief`/`gate-brief`
generation. `cmd_validate` now tags each issue as `(ERR|MISSING_REF, message)` at emit time —
severity no longer depends on the message containing the words "missing file" (P0.01 CODE-2).
A regression test proves an error whose text contains that phrase stays an error.
No CI change needed: `pytest.ini`'s `testpaths = tests production` (pre-wired in P0.07) already
collects `production/tests/`, and the workflow's `pytest` step runs it.
