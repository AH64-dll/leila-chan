# Handoff — P1.26: P0 gate C6: detect implementer/reviewer metadata drift

## Round 1  (2026-11-02, agent: commandcode)

### Summary

The tracker now treats the backend a report/handoff declares as evidence: `review` and `gate` default
`--reviewer` to the report's `- Reviewer backend:` line and refuse a contradiction unless an explicit
`--backend-override "<evidence>"` is recorded with the entry. `set … in_review` adopts a handoff-declared
implementer agent or refuses a contradiction (audited `--force` path), and `agent` records the contradicted
declaration as `agent_declared`. `validate` compares every recorded review and handoff against those
declarations and prints backend-drift warnings; drift on a **done** task fails `--strict`, while drift on an
open task stays advisory so in-flight rework is not blocked. The 35 legacy pairs that cannot be corrected
without rewriting `state.json`/reports are audited explicitly in `production/backend_audit.json`.
