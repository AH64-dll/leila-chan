### Deviations from the design bible
docs/07 §2 does not name a place for test code or vendored addons; additions only, no contradiction —
recorded here for the same DCR-style treatment P0.13 gives P0.05's silent choices:

1. `game/addons/` — Godot's required addon location; docs/07 §2 has no addons entry. Third-party code lives
   here and is excluded from lint/format via `excluded_directories`.
2. `game/tests/` — top-level test root (gdUnit4 scans `res://tests` via `-a`). Not in docs/07 §2.
3. `game/reports/` — gdUnit4's default report dir (HTML + JUnit XML); gitignored.
4. `--ignoreHeadlessMode` — gdUnit4 v6 **refuses `--headless` by default** (InputEvents don't reach the
   engine headless, so UI-interaction tests would silently no-op). We opt in explicitly; convention: keep
   suites logic-only. If scene/input simulation is ever needed, run the same cmd line without `--headless`
   on a display (or CI with a virtual display).
5. gdUnit4 chosen over GUT — richer asserts, parameterized tests, JUnit/HTML reports for P0.07 CI.
   Its editor plugin stays **disabled**; the CLI runner needs no plugin activation.
6. `tools/test.*` runs lint *and* tests (the single check command); `gdformat --check` is configured but
   opt-in rather than enforced in the pipeline — easy to add if the team wants format gating.
7. gdUnit4 ships `src/dotnet/GdUnit4CSharpApi.cs` — dead weight in the non-.NET build, kept vendored as-is.
