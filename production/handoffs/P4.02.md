# Handoff: P4.02 GDExtension libleila_llm

## Round 1  (2026-11-05, agent: haiku-worker)

### Summary
`libleila_llm` (class `LeilaLLM`) runs Qwen in-process: load, prompt through llama.cpp `common` (same chat session the
server uses), JSON-schema grammar, UTF-8-safe token streaming, cancellation, metrics. It is built from pinned sources
(llama.cpp `ddf48f85`, godot-cpp `e103d348`) by `native/build_linux.sh`. GPU backends are the official b12024 Linux
`libggml-cuda.so` and `libggml-vulkan.so`, loaded at runtime (`native/stage_gpu_backends.sh`).
