### C10 First-beat vs Any-beat Selector
`score.py` and `report.py` implement `--beat {first,any}`:
- Default is `first` (role-qa-tester gate requirement).
- `any` checks if any beat in multi-beat turns matches `feelings_ok`.
- In the 60-turn v1 run, both first-beat fit and any-beat fit scored **100.0%** (and pre-REV2: first-beat 91.7%, any-beat 95.0%).

### Deviations from the design bible
- **Dose 0 during stage 1 run:** Control vector is an execution flag on `llama-server`. The active test server was running without a loaded control vector, so both stage 0 and stage 1 ran at dose 0. Recorded explicitly in `results/2026-11-03_v1.json` metadata. P2.21 will evaluate stages 2–5 with dedicated server launches per scheduled vector dose.
- **`memory` rejection check:** docs/02 §6 rule 2 forbids schema words in `memory`, but using all JSON schema keys as forbidden words falsely flags valid noun phrases (e.g., `music box` because `music` is a schema key). `lab.py:check_memory()` restricts forbidden words to explicit metadata terms (`player`, `system`, `prompt`, `schema`, `stage`, `turn`, `model`) to avoid false rejections.
