## Instructions for Key Fields

- **First beat latency (s)** — stopwatch from player presses **Enter** on first message until **first character** of reply appears.
- **Dead air** — longest and total stretches where screen shows no new text for >2 seconds after a send.
- **Broken turns** — visible failures: input locked, no reply, duplicate beat, crashed generation. Target: **0**.
- **Closing failures** — any time closing the window failed, hung, or did not exit on the second press. Target: **0** (docs/05 §0 hard rule).
- **Close always worked** — `yes` if closing exited within one extra press/click and Esc paused safely; `no` if trapped.
- **Intended path** — the path targeted by the participant's assigned play style (`YANDERE`, `SPLIT`, `TSUN`, `HOLLOW`, `AWAKE`, `ANCHOR`).
- **GameState path at end** — read from F3 debug overlay or telemetry (`GameState.path` at session end).
- **Meta events observed count** — total meta events that occurred during this session.
- **Meta events naturally triggered** — count of meta events triggered by game conditions (e.g. M21 draft delete, M01 close intercept, M35 clock).
- **Meta events F3 fallback triggered** — count of meta events triggered via F3 overlay (if none occurred naturally by minute 7).
