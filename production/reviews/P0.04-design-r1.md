## Pillars (docs/01 §0)
1. **She is not scripted.** The run is prompt-driven; no dialogue tree or canned line. The beats are the model's own output, and the deterministic probe reproduces them exactly.
2. **The game owns the truth, the model owns the voice.** The experiment only measures model output; it has no game state or clamping path. The schema's `mood`/`memory`/`action` remain suggestions for the future Director, not state changes.
3. **Three engines of dread.** Not touched. The sweep gives the physical dose tool that later spikes and paths depend on; no slow-burn or trigger rule was changed.
4. **Her sickness is physical.** Strongly supported: the same model at scale 4 with the malice vector produces dark inner thoughts and possessive speech; the live re-run confirms the effect is the vector, not a text trick.
5. **Fourth wall as a scalpel.** The v3 stage-4 prompt enables fourth-wall suspicion for the experiment only; no game meta event, offer, frequency, closing or Esc rule was added or weakened. The scale-12 output confirms why P1.19's safety filter is mandatory before any display.
