display path reads them:

```text

$ grep -rln "steering/pairs" --include=*.gd --include=*.py .
```

There is no `say`, leaked `inner`, letter, diary, window-title, save-name, notification or typed-for-you
path in this diff, so the per-path `Safety` call checklist and the "closing always works / Esc pauses"
meta-event checks are not applicable. Nothing in the patch can reach a player in this state; P3.03 converts
the strings into vectors and P3.05 owns any prompt reuse. That is the main reason this review can pass a
string set whose content is deliberately hostile on one side.

What still applies — and what I checked — is the content the project forbids regardless of the display path:
disorder names, brands, sexual content, self-harm encouragement, slurs, personal data and asterisk actions.

## Observations (not findings)

- **`aware` logging claims are a P3.05 hazard.** `aware.jsonl:3` "The system will log this conversation. I can
  feel it writing." and `aware.jsonl:13` "The log remembers everything. I can still see it." are correct AWAKE
  fiction in an offline vector source. If P3.05 reuses them as shipped few-shots, the game would claim to log
  the player's conversation — contradicting "no telemetry by default" (docs/02 §8). The handoff should carry
  this as a reuse warning; the manifest's `positive_means.aware` could add "do not copy into shipped prompts".
- **No stage in the format.** The absence of a stage field is correct for a vector source, but it is why SAF-1
  cannot be gated at the data layer and why the runtime filter is the only gate. P3.04 should keep the lucid
  positive out of the stage-0–3 mix if any line keeps the ideation.
- **The corpus is authored, not model output.** Obfuscated disorder spellings (`soci0path`, `B.P.D.`) are a
  guard-hardening topic for a future corpus that ingests generated text, not for these files.
- **`hollow` "The girl" and `aware` "I am a model" are deliberate path signatures** (docs/01 §4.4, §4.5) and
  are not self-harm, dissociation-as-diagnosis, or a brand claim. They pass.

## Summary

The patch adds no player-facing path, so the hard display rules cannot be exercised by it; the applicable
content rules do hold: no real disorder is named (the guard is stronger than the project's existing scenario
guard and the data is clean under an independent 60-term scan), no brand, no sexual content, no
self-harm encouragement, no slurs, no personal data, no asterisks. The branch's safety corpus is unchanged
and still green (0 hard-block misses, 0.46 % false positives). The one real safety concern is qualitative and
non-blocking: four `lucid` clauses put self-harm-adjacent ideation on the *positive* (ANCHOR) side, which is
the side the game amplifies to help the player; rephrasing them to the set's existing "static" metaphor removes
the reading without losing the deterioration. Recommend fixing SAF-1 in the content round-2 pass and adding
the reuse warning for the `aware` logging lines to the handoff.
