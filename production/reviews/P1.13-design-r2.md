## Five pillars
1. **She is not scripted.** All her text arrives as streamed say chunks and is rendered verbatim post-filter; the UI never invents lines. Only authored strings are the indicator templates in `ui.json`, which are frames, not dialogue. ✓
2. **The game owns the truth, the model owns the voice.** This kit touches no meters/stage/path state; all state-changing signals (submit, pause, stage setter, filter setter) are inputs the owning scene wires. Presenter-only surface. ✓
3. **Three engines of dread.** Indicator stage flavour is driven by `set_stage()` from game state, not from anything the model streams in. ✓
4. **Her sickness is physical.** Stage ≥ 3 dot stutter and stage ≥ 5 "*you*" tail are true presentation shifts keyed to real instability stage; all four stage markers are asserted in the tests. ✓
5. **Fourth wall as a scalpel.** The only meta-adjacent surface shipped is the stage-5 "*you*" indicator roll — stage-gated, 0.2 chance, seeded for determinism/replays. Inbound-and-capped, exactly per docs/02 §4. ✓
