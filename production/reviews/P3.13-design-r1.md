| DES-1 | S2 | `game/autoload/Settings.gd:136-143` + `game/autoload/PauseMenu.gd:271-273` | docs/02 §8 allows the gated self-harm/threat lines only when the player **explicitly selected** `content_level = full` (user-approved D11 / P1.19 DCR-1). ## Pillars (docs/01 §0)

1. **She is not scripted** — no dialogue was added; all menu copy is static UI chrome in `ui.json`. Fine.
2. **The game owns the truth, the model owns the voice** — the setting is game state, written only by the player through `Settings`; the model cannot touch it. Fine.
3. **Three engines of dread** — untouched.
4. **Her sickness is physical** — untouched (the dose/corruption caps still read the real stage).
5. **Fourth wall as a scalpel** — preserved: Deep is opt-in and default Standard, and the panic key makes every meta event exitable, which is exactly the rule the fourth-wall events depend on.

## Summary

The surface is the right shape for the design: one settings screen reachable from the Title and from
Esc, the content warning and resources link on it, M26's locked dose row at stage 4, a real calmer cap
read from the same field Safety and Steering use, and Esc working through `_input` at any moment
including a held M01 close. The blocker is DES-1: the Calmer-mode checkbox writes
`content_level = full` when switched off, so the explicit consent docs/02 §8 (D11) requires for the
gated lines is obtained from an unrelated toggle — a fresh profile can reach `full` in two clicks and
never see the Content-level selector. The rest is documentation debt: the new autoload is missing from
docs/07 §2, and the Title/New Game Esc changes are not in the handoff's deviations.
