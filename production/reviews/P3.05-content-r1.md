## The DCR-2 question: does the enum-line cost break the design intent or only the fixed-block budget?

**Only the budget as the docs wrote it — not the design intent.** The overrun is real (I reproduced it), but it is a per-turn legality list, not authored voice, and the accepted D15 restatement covers it.

- **The numbers.** With the builder's exact separator and no trailing newline, the line costs **62 / 77 / 91 / 122 / 137 / 143** tokens at stages 0–5 (`action: none`, the normal cell). With `end_date` offered at stage 2 (its gate is stage 0) the line is **94** tokens. The worst fixed assembly is 899, so the stage-2 full message is **990** (991–993 with an offer). The handoff's 990 is the empty-offer cell; the difference does not change the decision.
- **What the fixed block is.** The part prompt content controls — persona 181 + player 9 + stage 138 + path 141 + rules/glosses 407 = 876 at the golden cell, 899 worst with a 16-char name and the SPLIT runner-up — is under 900. The enum line is built by `PromptBuilder._offered_line` (`game/autoload/PromptBuilder.gd:308-327`) from `TurnContext.offered_values` (`game/llm/TurnContext.gd:150-164`); the JSON schema already constrains the same values, so the line is a legality aid, not content.
- **The design intent is context economy, not a magic number.** docs/07 §3.1 gives an 8192-token context; 990 system + 1500 history + 600 output + 150 scene leaves ~5000 tokens. There is no 4B quality cliff between 900 and 990, and the lab's validity at dose 0 is 100% with the line present in the real server prompts (the results' `usage.prompt_tokens` include it).
- **What was actually broken** was the documentation and the debug signal, not the prompt: docs said one "900" for two different things, and the builder still counts the enum line inside the fixed `rules` layer — a real stage-2 build reports `fixed: 966, system: 966, over_budget: ["system"]`, contradicting D15's fixed-block definition (design DES-3). D15's restatement (fixed ≤ 900, per-turn ≤ 200, whole ≤ 1100) is the right shape and every stage fits it; the builder's grouping should follow.
- **Do not cut persona to hide it.** The right saving, if one is ever wanted, is the cue list (8–22 values by stage, 22 at stage 5, and "most beats use 'none'"), not Leila's voice. The handoff's refusal to paper over the line is correct.
