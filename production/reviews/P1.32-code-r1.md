| CODE-1 | S3 | `game/llm/TranscriptRedactor.gd:123-131` | The length-change fallback folds the whole reply onto the first `say_chunk` for **any** length change, not only a redaction. The filter's `filter_text` normalizes whitespace (`SafetyText.collapse_ws`, `game/autoload/SafetyText.gd:180-195`), so a benign reply containing a double space — or a variation-selector/ZWJ emoji that `sanitize` strips — is rewritten although no span was barred: probe C on the real filter turns chunks `["Hi!  I", " am here."]` into `[14, 0]`. A three-beat reply then replays entirely under beat 0 and loses its streamed boundaries in the corpus. No text is lost and nothing unbarred, so S3. | Keep the filter's `redacted` flag in the gate (`Safety.filter_text` already returns it; `SaySafetyGate.gd:137-140` drops it) and return from `_redact_events` untouched when no span was applied; take the fold path only when the text was redacted **and** its length changed. |
| CODE-2 | S3 | `game/llm/TranscriptRedactor.gd:85-95` (`_redact_messages`); `game/autoload/PromptBuilder.gd:258-279` | The system message is skipped as "authored data", but `PromptBuilder._memory_layer` injects model-authored `memory` facts into it. | CODE-3 | S3 | `game/llm/TranscriptRedactor.gd:69` | `redact_record` scans `record["prompt"]` only when it is an `Array`, but `TranscriptLogger.log_turn` documents and validates `prompt` as Array/Dictionary (`game/llm/TranscriptLogger.gd:184`, `:316`).
