## Deviations and their legitimacy
- **Stage-1 dose 0:** llama-server had no control vector loaded; `results meta.dose_note` records it. Legitimate (server launch flag; P2.21 follow-up), but the 100.0% emotion-fit number is therefore a **dose-0** measurement, not the docs/02 §9 stage-1 schedule. This is stated openly in the handoff, report, and set notes — no fabrication.
- **`memory` meta-word list narrowed** (docs/02 §6 rule 2 says "no schema words"). `game/data/prompts/rules.md` uses keys `read, inner, music, fx, beats, mood, memory, action`, so a literal schema-key list falsely rejects benign facts like `gave me a music box` (`music` is a key). `lab.check_memory()` instead blocks explicit meta words (player, system, prompt, schema, turn, model, snake_case intent labels like `jealousy_bait`) and tests both directions (`test_memory_meta_word_rejected_but_music_box_benign` asserts `gave me a music box` == [] rejects and `player met Sarah today` is rejected). Closest-faithful reading, recorded as a deviation in the handoff — accepted.
