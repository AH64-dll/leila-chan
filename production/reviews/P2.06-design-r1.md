## Judgement on the four named areas

- **Effects table by stage.** Exact. `docs/07 §3.4`'s five bands map one-to-one onto gates 1/2/3+3/4+4/5+5 and `docs/01 §3`'s Text FX column; `test_stage_gates_match_the_docs` asserts the full plan string per stage, `test_data_cannot_lower_a_gate` proves the code rule, and `_normalize` clamps chances. I found no effect appearing a stage early or late; the stage-5 Text FX row's second half ("typing in your input box") is the M22 meta action, not this filter. Two composition details are off (DES-1) and the frequency of the two earliest bands leans against the doc's adjectives (DES-5).
- **Display-only deviation for reverse/bleed (DCR candidate).** Support, with amendments — see DCR 1. The reasoning is sound: the typewriter consumes the streamed beat live (docs/07 §3.4 + docs/02 §4), so characters already on screen cannot be retracted; appending a ghost line is the only faithful option that does not delay the beat past the 1.0 s first-beat budget (docs/07 §4). It is display-only: the spoken line, the chat log entry and the reversal source are all the scanned beat text. One correction: the proposed doc text says "dimmed echo" but the implementation indents and underlines (U+0332) in the normal text colour with no colour/BBCode change (`Corruption.gd:395-406`; screenshot `04_stage5_bleed_reverse.png`) — the doc text must say "indented and underlined", not "dimmed".
- **Reduced-motion scope.** The behaviour is defensible and testable, and it is the *smallest* subtraction that removes the shimmer/smear the accessibility option exists for; the textual effects and their seeded outcomes are preserved bit-for-bit by keeping the rolls (`test_reduced_motion_removes_only_the_visual_effects`). But the bible never says what reduced motion covers for text (only M27's cursor drift, docs/05:64, and photosensitive gating of flicker/invert, docs/02 §2.3), so this is a silent-doc case that protocol §6 wants filed as a DCR — the handoff states it as a deviation bullet without a doc/section or proposed text (DCR 2). Photosensitive mode needs nothing here: the filter emits static glyphs only, so it cannot violate the 3 Hz rule.
- **Safety-scan ordering (no safety bypass).** Confirmed, by code and by test. Every displayed chunk is filtered before corruption: `ChatUI.say_chunk` (pass-through in Date because `Director` already scanned through `SaySafetyGate`, `Director.gd:468-492` and the holdback tail `:543-551`), `replace_beat` for docs/02 §7 repairs (Director scans at `:686` before the UI), and the opening beats (`Date._scan_opening_say` fails closed to `SaySafetyGate.redact`). The stage-5 echoes are composed from the already-scanned `_beat_text`, so they cannot introduce unscanned words, and no corruption primitive can restore barred text: bars are not letters (`_is_content`), redaction only replaces with more bars, and strike corrections come from a fixed data pair list. `test_corruption_runs_after_the_safety_filter` proves the order (uppercase from the filter appears inside the corrupted text, a blocked phrase stays barred); `test_reject_turn_stays_legible` proves a refusal is shown exactly as Safety wrote it. I found no path where corruption output is displayed without a prior scan.

## Pillars (docs/01 §0)

- **1. She is not scripted** — the filter post-processes the model's own words; nothing here is a dialogue tree or a canned reply. The only inserted words are the game's fixed detritus (pair corrections, stranger names, bars), the same class as the Safety redaction.
- **2. The game owns the truth, the model owns the voice** — gates, caps, seeds and the calmer ceiling are game rules; the model cannot request an effect and cannot see the plan.
- **3. Three engines of dread** — the effects ride the stage machine, so the slow burn always advances; the spike leg comes from the dose/state, not from this file. Note DES-5: the strike rate saturates at stage 2, so later stages escalate by *kind* more than by strike frequency.
- **4. Her sickness is physical** — corruption keys off `GameState.stage`/the UI stage, i.e. the steering ladder; stage-0 noise is impossible (exact plan strings per stage), so no late-stage weirdness appears at low dose.
- **5. Fourth wall as a scalpel** — stage-5 bleed/reverse stay inside the text box, gated at 5 and uncommon (0.45/0.25 per beat); no OS/window effect is added here.
