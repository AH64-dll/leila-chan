## Five Pillars (docs/01 §0)

1. **She is not scripted:** The ending line is generated live by the pinned LLM using the run's path and stage; authored frames stage the scene without hard-coding dialogue trees.
2. **The game owns the truth, the model owns the voice:** State rules (`Endings.evaluate()`) select the ending; the model only returns a single filtered string clamped to `{"line": string}`.
3. **Three engines of dread:** The ending reflects cumulative meters, stage, and path; no artificial jump or unexpected bypass.
4. **Her sickness is physical:** Steering dose is applied to the live generation according to the run's stage (`LLM.generate` preserves stage dose).
5. **Fourth wall as a scalpel:** E10 handles AWAKE's meta premises cleanly within narrative boundaries; no invasive OS tricks or unpaused traps.
