## Observed behaviour

1. **Title screen drift & interactions (M06, M07, M02)**:
   - At stage 1: Standard title screen with no portrait and New Game clickable.
   - At stage 2: Bust crop portrait appears (sprite "03"), static eyes.
   - At stage 3: Bust crop portrait (sprite "09") shifts region tracking cursor position; eye offset is 2 px native (4 px display). Under reduced motion, eye shifting is suppressed.
   - At stage 4: New Game is disabled with tooltip "Why would you want a new one?"; 5.0 s hover or focus unlocks New Game button. Continue/Settings/Quit remain active throughout.
   - At stage 5: Title label changes to "Leila", bust crop uses sprite "25".
   - M02 she-closed marker: Displays altered title and subtitle note ("You came back. I closed it so you'd know how it feels.") once, consumed upon reading.

2. **Replicas and in-game scenes (M09, M10, M11)**:
   - M09 fake crash displays in-window `CanvasLayer` Control with [Wait] and [Close]; laugh cue triggers; both buttons dismiss cleanly back into the date.
   - M10 fake update presents progress bar that asymptotically approaches 99% (`_stall_at = 0.99`) using exponential decay `1.0 - exp(-elapsed / k)`; [Later] button dismisses immediately.
   - M11 credits roll her name lines, pauses 3.0 s on "That's not how it ends.", then dismisses. Under reduced motion, displays static page rather than vertical scrolling.

3. **Window title & cold open (M12, M03)**:
   - M12 window title extracts current turn's `say`, scans via `Safety.filter_text`, clamps to ≤40 chars at word boundaries, and calls `DisplayServer.window_set_title()`. Fallback routes to system chat log message when title bar is unavailable.
   - M03 cold open: `Boot.gd` queries `cold_open_requested()`, loads latest save, and routes directly to `Date.tscn`, skipping `Title.tscn`. Once in Date, her opening line is spoken automatically once chat is idle.

## Deviations and DCRs in the handoff

| Handoff deviation | My verdict |
|---|---|
| **M10/M11 roll chance**: Deterministic roll seeded per (day, event, scene) at `scripted_chance` 0.34 at scene boundaries rather than guaranteed firing at every eligible scene. | **support** — Prevents event flooding across scene boundaries while preserving docs/05 §1.1's characterization of M10/M11 as rare S events. |

| **Module reset propagation**: `MetaDirector.reset_session()` calls `reset_session()` on all mounted effect modules. | **support** — Essential for preventing stale full-rect mouse-blocking UI from swallowing input in subsequent sessions. |

## Pillars (docs/01 §0)

1. **She is not scripted** — All event copy and fallbacks live in data (`meta_messages.json`); the LLM voice remains autonomous, reacting to EVENT context notes.
2. **The game owns the truth, the model owns the voice** — State transitions, stage gates, quit detection, and timing calculations are strictly owned by engine code (`MetaEventsM01`, `MetaDirector`, `MetaStateM01`).
3. **Three engines of dread** — Meta events scale progressively across stages (St 2 subtle drift -> St 3 eye tracking & close interception -> St 4 fake crash/update/quit -> St 5 name title & fake credits).
4. **Her sickness is physical** — Visual and UI corruption accompanies meta events; eye tracking and text effects reflect her escalating condition.
5. **Fourth wall as a scalpel** — Events are rare, capped, gated, and offered; player safety and control are uncompromised (second close press always quits; Esc always pauses).
