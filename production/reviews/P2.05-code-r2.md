| CODE-1 | S3 | `game/llm/TurnContext.gd:90-98` | A `stages` entry whose value is not an object — `{"0": 5}`, `{"2": null}`, `{"3": [1, 2]}`, or a string row — still increments `rows_from_data` (`:91`), although `_numeric_sampling()` returns `{}` for anything that is not a Dictionary (`:115-124`) and `_stage_row()` then fills all four columns from `SAMPLING_FALLBACK` (`:105-110`). Because the counter is not zero, the `rows_from_data == 0` warning (`:95-98`) never fires: the whole table silently reverts to the in-code docs/02 §9 copy with no log line, which is the exact failure round-1 CODE-1/DES-3 asked this warning to surface. Observed in the loader probe above (`scalar-row`/`null-row`/`array-row`, no `WARNING` line). Trigger: a hand-edited or mispacked `sampling.json` with a scalar/null/array row value. Impact: a build runs on the in-code table believing it read the data file, and nothing in the log says otherwise. | Count a row only when it is a row object, or warn per non-object row. Minimal: assign the raw value first, feed it to `_numeric_sampling()`, and increment only when it is a Dictionary. |

```gdscript
			var raw_row: Variant = stages[key]
			table[stage] = _stage_row(stage, _numeric_sampling(raw_row))
			if raw_row is Dictionary:
				rows_from_data += 1
```
