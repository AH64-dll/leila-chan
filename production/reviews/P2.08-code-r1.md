### CODE-1 — `requires: "all"` ANDs only the model detector

`close_turn()` decides a `requires: "all"` row with `_any_source(_matched.get(id, {}))`, which is `keyword or event or clock` (`:511-520`). Two shapes therefore fire on evidence that fails their own detector spec:

- three declared detectors: keyword + model + clock, `clock.day_gte = 10`, evaluated on day 1 with the keyword matched and the read matched → fires at strength 1.0:
  ```text
  begin: []
  close fired count: 1
  close detail: [{ "id": "TX1", …, "strength": 1.0, "agreement": "both", "effects": { "meters": { "instability": 8.0 }, … } }]
  ```
- two non-model detectors: keyword + `clock.day_gte = 10`, `requires: "all"` → each condition alone is enough:
  ```text
  K+C all / clock FALSE, keyword true -> 1 firing(s)
  K+C all / keyword FALSE, clock true -> 1 firing(s)
  ```

`begin_turn()` has the same OR for `all` rows that carry no model detector (`:140`), and the deferral at `:138` only fires when `_needs_model()` is true, so an `all` K+C row never waits for both. The authoring contract says otherwise in three places — `data/triggers.json`'s `doc` ("`all` = every declared detector must agree and the effect is full"), `_parse_row()`'s doc comment, and `tests/test_triggers.py:135-138` ("`requires: all` means 'every declared detector must agree'", hence its ≥2-detector rule).

Impact: any catalogue that declares `requires: "all"` on three detectors, or on two non-model detectors, silently bypasses the declared stage/day/absence gate and reports agreement it did not get. No shipped row and no docs/01 §5 row has that shape today, so the defect is latent — but the field exists precisely so P2.10 (T01, T05) and P3.07 author rows against it, and the fix is five lines. The intended reading is visible in the inline comment at `:177-179` ("once M agrees with the sources matched earlier this turn"); the OR is an oversight, not a choice.

```gdscript
		if String(rec["requires"]) == "all":
			if not _all_sources(rec, _matched.get(id, {})) or not _eligible(id, rec, ctx):
				continue
```

```gdscript
## `requires: "all"`: every declared non-model detector must have matched this
## turn (the model detector is the one being decided now, in close_turn()).
func _all_sources(rec: Dictionary, sources: Variant) -> bool:
	var matched: Dictionary = sources if sources is Dictionary else {}
	for detector: String in (rec["detect"] as Dictionary):
		if detector == "model":
			continue
		if not bool(matched.get(detector, false)):
			return false
	return true
```

The same helper belongs in `begin_turn()` for `all` rows without a model detector — the deferral stays, the firing test becomes the AND:

```gdscript
		if String(rec["requires"]) == "all" and _needs_model(rec):
			continue  # agreement is decided at close_turn
		var satisfied := (
			_all_sources(rec, sources)
			if String(rec["requires"]) == "all"
			else _any_source(sources)
		)
		if not satisfied or not _eligible(id, rec, ctx):
			continue
```

### CODE-2 — the M wire and the C clock inputs have no test

`game/autoload/Triggers.gd:38-44` is the M detector's only production entry: `_ready()` subscribes to `Director.turn_completed`, because `Director.gd` is at the gdlint line cap. `TriggersTest` exercises `TriggerEngine.close_turn()` directly and `Triggers.begin_turn()` / `Triggers.handle_engine_event()` through the autoload, but never `Triggers.close_turn()` and never the signal — and nothing at all exercises `Triggers._context()` (`:215-229`), `_local_hour()` (`:239-245`) or `_absence_hours()` (`:247-251`); `test_clock_detection_day_hour_and_flags` passes `hour` straight to the engine. A changed signal signature, an autoload-order change or a timezone regression would keep all 606 gdUnit cases and 373 pytest cases green while the M detector (the agreement input) or T16's night window silently stops firing. I checked both by hand and they are correct today (see "Verification I ran"), so this is coverage debt rather than a defect: one case that emits `Director.turn_completed` with a synthetic catalogue and asserts the queued line plus the 0.5/1.0 split, and one `set_clock` case for the T16 window, close the hole.
