| CODE-7 | **S3** | `game/autoload/MetaDirector.gd:432-441` (`_inside_user_dir`) | **The gate accepts a write target Godot cannot open.** The path is lowercased before the scheme check, so `USER://letters/` is "inside `user://`" for the gate, while Godot treats resource schemes case-sensitively (`FileAccess.open("USER://…")` returns null — r1's attack row 12). | CODE-8 | **S3** | `game/autoload/MetaDirector.gd:214-222` (`turn_events`), `game/tests/MetaOfferPromptTest.gd` | **The handoff's "a retry de-duplicates" has no test.** Both `MetaOfferPromptTest` cases script a non-empty `say`, so `_start_turn()` is never re-entered and the `merged.has(line)` branch is dead code in the suite.
