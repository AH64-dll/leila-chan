## Pillars (docs/01 §0)

1. **She is not scripted** — no dialogue added; every new string is static UI chrome in `ui.json`.
2. **The game owns the truth, the model owns the voice** — content level, immersion and the calmer cap
   are game state written only by the player through `Settings`; the model cannot touch them.
3. **Three engines of dread** — untouched.
4. **Her sickness is physical** — the dose and corruption caps still read the real stage; the calmer
   switch remains the same field those systems already honour.
5. **Fourth wall as a scalpel** — Deep stays opt-in and Standard the default; the panic key keeps every
   meta event exitable, and the content warning/resources link are the first rows of Settings.
