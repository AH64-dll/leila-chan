## Findings

| ID | Sev | Where (file:line) | Problem | Suggested fix |
|---|---|---|---|---|
| DES-1 | S3 | `game/tools/scenario_playthrough.gd:175-186` (with `:124-133`) | The new harness feeds the same event line to the prompt twice on every `at_turn` turn. `ScenarioLoader.resolve_scene()` already returns the turn's event in `scene["event"]`, and `PromptBuilder._scene_layer()` renders it as `EVENT: …` (`game/autoload/PromptBuilder.gd:249-252`). `_turn_events()` then appends that same line to `ctx["events"]`, which `_events_layer()` renders again (`:281-291`). docs/08 §1 splits the layers: the scene layer is "scenario.prompt + current event", the events layer is "EVENT / TRIGGER / OPPORTUNITY lines this turn only" from the Director/Triggers. Evidence in the committed artifact: D03 turn 1's scene estimate is **110** (`D03_park_bench_s3_YANDERE.md:34`, no event); turn 2's is **148** (`:50`), and 148 = 110 + 19 + 19 with the event line (19 tokens at 3.6 chars/token) counted in both layers. So the transcripts — this task's acceptance evidence — were generated from a system prompt the game will not send, and the scene block sits at 148/150 only because of the duplicate. | Pass only the `--fires` line in `ctx["events"]`; keep `scene["event"]` for the prompt (the loader already puts it in the scene layer) and, if the transcript should still show it, print `scene.event` in `_turn_lines` separately. Then regenerate the six transcripts so the per-turn scene figures are single-counted. |

### DES-1 suggestion

```gdscript
func _turn_events(scene: Dictionary, turn_no: int) -> Array[String]:
	var events: Array[String] = []
	# scene["event"] is already rendered by PromptBuilder's scene layer
	# (docs/08 §1: scene = prompt + current event). Only the staged trigger
	# line belongs in the events layer.
	if _fires.has(turn_no):
		var trigger_line := ScenarioLoader.get_event_for_trigger(
			_scenario, String(_fires[turn_no]), _player
		)
		if not trigger_line.is_empty():
			events.append("EVENT: " + trigger_line)
	return events
```
and in `_turn_lines`, build the display line from `scene.get("event", "")` plus `events` so the transcript still
shows the at-turn line.

## Pillars (docs/01 §0)

1. **She is not scripted** — the scenarios provide frames only (goal, prompt, stage variant, path twist, 1–3 staged
   events); every spoken beat in the 46 turns is model output. The one scripted element, the opening beat, is the
   pre-existing P1.15 engine opener, not a dialogue tree.
2. **The game owns the truth** — stage and path come from the game; the loader only resolves text and the
   events are engine-scheduled. The model never sets a stage, a path or an ending.
3. **Three engines of dread** — the slow burn is carried by the 0–5 stage variants, the paths by the twists, and
   the spikes by T01/T02 `on_trigger` events; all three are visible in the data and in the transcripts.
4. **Her sickness is physical** — variants are keyed to the stage/dose, and the stage-5 texts are written to feed
   the Corruption layers (D04 "raining inside the umbrella", D11 photos past the ceiling), not to fake escalation.
5. **Fourth wall as a scalpel** — game/code awareness lives only in the AWAKE twists (one sentence each) and is
   path-gated; no meta line is free. The stage-4/5 `inner` leakage on other paths is model output and is already
   flagged for P3.05 in the handoff.
