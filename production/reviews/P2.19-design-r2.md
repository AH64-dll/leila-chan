## Pillars (docs/01 §0)

1. **She is not scripted** — the new screens are authored frames P5.03 sanctions; the date's free-typed
   conversation path is untouched; the interrupt deferral keeps day scenes date scenes rather than
   inventing scripted event days. Pass.
2. **The game owns the truth, the model owns the voice** — the night order, the +3 burn, the stage
   crossing, the path rule, the date-only pool and the played-set bookkeeping are all game code/data; the
   model is never asked for night state. Pass.
3. **Three engines of dread** — the slow burn always advances (+3/night), paths still come from
   accumulated player behaviour, triggers are not involved in the changed paths. Pass.
4. **Her sickness is physical** — the night's crossing still emits `stage_transition` and `LLM` rebinds
   the steering dose; only the 2–3 s visual glitch lacks a host during the night (P2.15 follow-up,
   unchanged). Pass with that follow-up.
5. **Fourth wall as a scalpel** — N01/N12 add no new meta action, file or window trick; the texts are her
   voice inside the night screen. Pass.

## Summary

Round 2 makes the day/night loop the bible's loop in the two places it was not: a day is now a date
scene by construction (0/64 non-date picks on the shipped pool, where seed 0 used to open on the I01
phone call), and N12's ten seconds are genuinely "nothing" — the day/night chrome hides for the black
beat and returns with the morning line. The played set is reconciled at every hand-off, so a night-save
Continue cannot replay the day's date, and the screen's own promise ("click or press Space") now holds
through the real viewport, with both date-end routes scene-tested. The interrupt injection and the doc's
"or trigger" end remain explicitly deferred to P5.02/P5.06 with named owners, and the Esc/pause question
is still the producer's/user's call until P3.13. One S4 (the handoff's "seventeen" vs the plan's fifteen
interrupts) is noted for the next handoff edit; it does not block the merge.
