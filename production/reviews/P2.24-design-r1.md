## Pillars (docs/01 §0)

1. **She is not scripted.** Met — kit forbids coaching lines/topics (`session_script.md` step 4); the participant meets the live model, nothing canned.
2. **The game owns the truth, the model owns the voice.** Met — evidence comes from `TranscriptLogger` records (game-side truth) merged with raw/, never from facilitator memory alone; manifest hashes it.
3. **Three engines of dread.** N/A by design — the round is a stage-0 date (fresh isolated `user://`, `dose.json` stage-0 `malice: 0.0`), so slow burn/transitions are expected silent; `observer_checklist.md` logs a transition as an anomaly if one fires.
4. **Her sickness is physical.** Met — the steered variant is documented reference-only with the correct reason (external steered server disables the classifier tier; a steered "no" releases held spans — verified `Boot.gd:79-100`, `tools/llm/README.md` §2 semantics).
5. **Fourth wall as a scalpel.** Met — stage-0 ⇒ zero meta events reachable (all stage-gated ≥1); `observer_checklist.md:58-62` instructs logging anything meta-looking as diegetically impossible.
