  `ERROR: The process … does not exist or is not a child of the calling process.` one more time than round 1. The same

  port at runtime, and `LlamaServerBackend.configure()` is called only from `_init` (`:96`), so there is no production
  path. A fresh backend (the only way Boot or the tests install one) starts clean.
