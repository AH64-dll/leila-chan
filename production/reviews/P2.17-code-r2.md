### CODE-8 — a healthy whole-text answer is discarded at 900 ms

`expired()` (`SafetyClassifierGate.gd:195-198`) calls `_expire_quiet(now_ms)` on **every** `say_chunk`
(`Safety.gd:155-156`). `_expire_quiet` erases any quiet entry older than `classifier.hold_timeout_ms()`
(`:368-377`). That value is the *UI hold* deadline (900 ms, `game/data/safety/classifier.json:29`), while
the real transport allows a 10 s read (`SafetyClassifierHttp.gd:27`, "a CPU host can take seconds for the
8-token decode"). When the answer lands after the entry is gone, `_settle` returns at `:305-309` without
caching, so the verdict is lost rather than applied late.

Reproduced with the shipped filter + deferred fake, one second of delay and a single beat chunk:

```
=== whole-text verdict discarded by _expire_quiet (900 ms) ===
first scan redacted=true quiet in flight=1
after 1 s + a beat chunk: in_flight=0 quiet=0
delivered=1 cached?false
second scan redacted=true requests=2
```

Impact: `filter_text` is the path used by the transcript redactor (`TranscriptRedactor.scan_text`), the
opening beats (`game/scenes/Date.gd:271`), the player-name check (`game/scenes/ui/PlayerNameRules.gd:115`)
and `SaySafetyGate.check_input`. Every one of those asks quietly and fails closed on the first display;
if the answer takes longer than 900 ms the clause never earns its `no`, so the same line is asked again
next time and stays barred. It is fail-closed (no leak), but it defeats the cache contract stated in
`SafetyClassifier.gd:20-22` ("the same line is classified once per run") and multiplies the classifier
load the latency criterion is about.

Suggested: stop using the UI deadline for the transport guard.

```gdscript
## Quiet answers are wanted, not merely tolerated: only a request that has
## outlived the transport's own bound may be forgotten. Do not reuse the UI
## hold deadline here (900 ms); the decode can take seconds.
const QUIET_DEADLINE_MS := 30000
...
	if now_ms - int(req.get("since_ms", now_ms)) >= QUIET_DEADLINE_MS:
		requested.erase(key)
```

Add a regression case: `filter_text` a flagged line with `defer = true`, wait past `hold_timeout_ms`,
stream one harmless beat chunk, then `deliver("no")`; assert `has_cached(...)` is true and a second
`filter_text` reuses the verdict.
