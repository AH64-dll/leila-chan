## Hard rules (docs/05 §0), one line each

- [x] **Every displayed model text passes Safety** — the path map above; the leak is the only new path, and
      it displays the filter's output verbatim. (`Safety.filter_text` result is the label's `text`.)
- [x] **Filter categories/actions match docs/02 §8** — verified live: harm to player ×2 phrasings, slur,
      disorder, personal data barred at stage 5/full; her self-harm and fictional threats open only at

      calmer or an invalid level.

      `Safety.filter_text` itself returns `FALLBACK_BARS` when its lists fail (`Safety.gd:216-221`), and
      `resolve_whole` bars any flagged span it could not classify (`SafetyClassifierGate.gd:231-251`).

      close press still closes (nothing in the leak path touches `NOTIFICATION_WM_CLOSE_REQUEST`).
- [x] **Esc → safe pause at any moment** — the label sets `mouse_filter = IGNORE`, grabs no focus and
      installs no input handler; `InnerLeakUITest::test_esc_still_pauses_while_a_leak_is_showing` drives
      the real `ui_cancel` path while the thought is on screen and asserts `pause_requested` fires.
- [x] **Files only under `user://`; no other process/OS dialog** — the leak writes nothing; `InnerLeak`
      only *reads* `res://data/inner_leak.json`. No letter/diary/window-title/save-name surface is touched.

      `word_by_word` → `instant`, `InnerLeakTest`/`InnerLeakUITest` cover it, render `05_…`).
- [x] **Photosensitive mode** — the leak is one static line for 1.0 s (ghost) / a word-by-word text
      reveal at 0.22 s per word (red); there is no luminance inversion, no full-screen flicker, nothing
      near 3 Hz. No `invert_flash`.
- [x] **Calmer mode caps at stage 3 and its dose** — `InnerLeak.plan` reuses `Corruption.effective_stage`
      (`InnerLeak.gd:127-129`), so stage 5 + calmer rolls the stage-3 ghost at 15 %; gated categories
