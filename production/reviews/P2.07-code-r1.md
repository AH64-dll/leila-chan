No S1/S2 findings. Specifically checked and found sound:
- **Cross-boundary routing**: the only new producer→consumer pair is
  `Director.turn_completed(turn_index, turn_data)` → `Date._on_director_turn_completed` (`Date.gd:429-434`)
  → `ChatUI.leak_inner`. `turn_completed`'s other consumers (`DebugOverlay._on_turn_completed`, the Date's
  own `turn_displayed` → `turn_completed` signal) are untouched; the handler null/`is_instance_valid`/`has_method`
  guards match the file's existing Date→ChatUI style, and the `is_connected` guard makes `_ready` re-entry safe.
  `turn_data` is schema-required to carry `inner` (`docs/02 §3`), and `str(turn_data.get("inner",""))`
  degrades to "no leak" when it is missing rather than erroring.
- **Cap semantics**: `_inner_leaked_turn == _turn_seq` (`ChatUI.gd:218`) is one leak per turn; `_turn_seq`
  advances only on the first `begin_turn_wait` of a turn (submit, or the Director's `_start_turn` for a
  monologue), so the Director's second call for the same turn cannot re-arm it. `abort_turn`/`reject_turn`
  both dismiss the hold and close the turn, so the cap cannot get stuck.
- **Roll determinism**: `seed_for`/`roll` are pure functions of (turn, effective stage, salt) — no stored
  RNG state; the `_turn_seq` counter is the only input the caller adds.
- **Data clamps** (`InnerLeak._normalize`, `:241-283`): chances → [0,1], alpha → [0,1], `hold` floored at
  0.1 s, `word_interval` floored at 0.01 s, `font_size` floored at 6, `behind_overlap` ≥ 0, unknown
  `reveal`/`align` fall back to the docs look, and the stage→style map is not read from the file. The
  suite pins this (`InnerLeakTest::test_data_cannot_restyle_a_stage_or_exceed_one`).
- **No node access in the rules file**: `InnerLeak` is pure `RefCounted`/static; the label owns drawing;
  the ChatUI owns the scan. That matches the repo's split for `Corruption`/`CorruptionSession`.
- **Main-thread cost**: one `Safety.filter_text` call per *leaking* turn on ≤ 90 chars
  (the corpus measures the whole-line scan path in µs); `_process` early-returns unless a leak is on
  screen and then does one `place_above` + one accumulator step. No blocking work.
- **Repo hygiene**: no secrets, no absolute paths, no binaries beyond the five handoff renders
  (the established `production/handoffs/media/` convention); `production/state.json`, `STATUS.md` and
  `phases/` untouched; commit prefixed with the task ID; handoff and journal entry present.
