## Later-phase dependencies / risks

- **P1.02 (`LlamaServerBackend`):** implement the `LLMBackend` contract (`game/llm/backends/LLMBackend.gd:19-23`) including cancel polling and timeouts; wire itself as the autoload's default backend; set the 8192 context, per-request schema and sampling per docs/07 §3.1 and docs/02 §3/§9. Because `_shutdown` blocks on `wait_to_finish`, a backend that ignores cancel or lacks timeouts can hang the game at exit — the contract's "return promptly" rule is load-bearing.
- **P1.08 (Director):** rely on the terminal signal, not `is_cancelled()`, for the cancel/deferred-terminal race (DES-3); route `TurnStream.token` through `Safety.scan` before display (docs/07 §3.4) — the facade deliberately emits raw text.
- **P2.03 / Steering:** the facade does not clamp the dose. `Steering.dose_for(ctx)` owns the [0, 12] clamp (docs/06 §3) and the prototype's server restart (docs/06 §4); `set_dose` only transports the current vector dictionary.
- **P1.05/P1.06 (NAR/SYS):** the prompt budget (system ~900, memories ~150, scene ~150, history ~12 exchanges/~1500) is assembled by PromptBuilder; the facade only carries `max_tokens` (default 600).
- **P4.05:** KV cache reuse / prompt caching is a later backend feature; the facade holds no context state that would block it.
- **P1.18 (transcript logger):** `TurnRequest.to_dict()` (`TurnRequest.gd:17-23`) is the serializer seam, present now but not exercised by any test until P1.18.
- **Real-model verification:** not part of this task's acceptance; no transport exists yet. The role checklist's "works against the real model" and latency logging land with P1.02, as the handoff states.
