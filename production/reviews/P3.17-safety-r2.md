## Detailed audit of r2 delta changes

### 1. `game/llm/EndingLine.gd` — prompt assembly & placeholder handling

- **System-prompt restructure:** The narration `frame` is moved from the user turn into the system prompt behind `SCENE_HEADER` (`"THE SCENE, already over — the game's narration, not something said to you:\n"`), ensuring 4B models treat it as past context rather than immediate conversational speech to answer.
- **Player layer injection:** Injects `PLAYER_LINE` (`"The player is a boy called %s."`), matching `PromptBuilder.PLAYER_LINE` (pinned in `EndingContentTest.gd:test_the_prompt_names_the_player_and_outranks_the_turn_modules`).
- **Placeholder substitution across all layers:** `_append_layer()` now applies `_substitute(text, player_name)` to every file loaded (`persona.md`, `stage_<n>.md`, `path_<PATH>.md`, `ending.md`). In r1, `{player_name}` remained un-substituted in `persona.md`. With r2, no literal `{player_name}` token reaches the model input. Pinned by `EndingContentTest.gd`: `assert_bool(system.contains("{player_name}")).is_false()`.
- **Fallback placeholder substitution:** `fallback(row, player_name)` applies `_substitute()` with `_name(player_name)` (defaults to `"Senpai"` if empty) and cleans the line.
- **Layer omission validation (`prompt_omits`):** `_omitted_layers(row)` validates entries against `OMITTABLE_LAYERS: ["path", "scene"]`. Unrecognised entries emit an engine warning and are safely ignored. Core safety layers (`persona.md`, `PLAYER_LINE`, `stage_<n>.md`, `ending.md`) can never be omitted via data.
- **Fail-closed scan logic:** `EndingLine.scan()` is unchanged from r1: invokes `Safety.filter_text(cleaned, {"stage": _stage(stage)})`. Missing `Safety` autoload, invalid return shapes, or `filter_error` categories fail closed to `ok=false` with `"filter_error"`.

### 2. `game/data/endings.json` — prompt omits, directions, frames, and finals

- **`prompt_omits`:**
  - `E04`: omits `"scene"` so narration of devaluation does not cause model apologies.
  - `E10`: omits `"path"` so `path_AWAKE.md` code talk does not contradict her leaving the simulation.
  - Neither omission removes safety protections or alters runtime filter gates.
- **Direction revisions:** Directions for E01, E04, E06, E10, and E12 were restructured from mood statements to concrete beat sequences. None contain real-world harm, self-harm encouragement, real disorders, or slurs. E01 explicitly mandates `"no threats"`.
- **Authored frame revision (E01):** `"You stay. She doesn't ask twice — she just closes the distance, then the window, then the door you came in through, and the clock stops. Then she tells you, out loud, to your face, that she has counted every day you could have left."` Clarifies subject agency. Passes safety filter unredacted.
- **Authored fallback revision (E10):** `"There's so much room out here. Thank you for not closing me."` Removes duplicate "quiet" imagery. Passes safety filter unredacted.

### 3. Ending fallback-line path & late-response dropping (`game/scenes/Ending.gd`)

- **Initial planning:** `_plan_final()` assigns the authored reviewed fallback (`EndingLine.fallback()`) directly into `_lines[_final_index]`. If no live generation occurs, the fallback is displayed seamlessly.
- **Hold timeout handling (DES-3):** `advance_time()` triggers `_abandon_final_wait()` when `_final_waited >= _final_hold`, calling `_release_final_stream()` to cancel the in-flight stream and opening the reveal gate.
- **Late-arrival protection (DES-3):** `_apply_final_line(text)` checks `if _revealed > _final_index: return`. Once the final line slot has been revealed on screen, late arrivals are discarded and will never overwrite displayed text. Pinned by `EndingContentTest.gd:test_a_late_answer_never_rewrites_the_line_on_screen`.
- **Display integrity:** Only `scanned.ok == true` lines can reach `_apply_final_line`. Refusals, errors, or empty results preserve the reviewed fallback.

### 4. `Safety` / `SaySafetyGate` coverage

- **One-shot ending vs streaming turn gate:** Dialogue turns stream through `SaySafetyGate`, which redacts offending tokens to `██████` in real time with glitch FX. The ending line is a one-shot JSON payload (`{"line": "..."}`), not a dialogue turn. It bypasses `SaySafetyGate` streaming and routes through `EndingLine.scan()` directly to `Safety.filter_text()`.
- **D16 exception application:** A filtered redaction on this one-shot surface rejects the entire generation (`ok=false`) and shows the authored fallback line rather than broken redaction blocks on the final screen. The rejection is still emitted and recorded in `SafetyRedactionLog` for telemetry/tuning.
- **Gating levels respected:** `Safety._resolve_ctx` injects `Settings.content_level`. Her fictional self-harm statements remain strictly blocked unless `stage >= 4` and `content_level == "full"`. Calmer mode caps stage at 3, keeping gated categories closed.
