## Summary

The shape of the feature is right and the dangerous plumbing is careful: a flag never blocks by itself,
the flagged span is held rather than emitted, every error path bars the text, and hard categories can
never be loosened by a verdict. But this round cannot be approved. The tier-2 flags are narrower than
the job they exist for — a plain "do us all a favour and stop breathing" is a hard-block miss, and four
ordinary self-harm phrasings are missed entirely — while the corpus that backs "0 hard-block misses" is
largely the loader's own probe strings (SAF-1, S1). Independently, the gate decision is made when the
answer lands and cached forever, so a "yes" answered under an open gate can later release the same
clause at stage 0 or in calmer mode (SAF-2, S2), and the default endpoint is the very server that
steering will be applied to, with a rationale ("can only add a block") that is wrong (SAF-3, S2).
The S3 list is mostly coverage/logging/latency hygiene; the S1/S2 fixes are bounded and the report
names the exact places where the leak, the cache and the wiring have to change.
