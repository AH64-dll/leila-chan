Concrete replacements — P2.09-DES-1 (`game/scenes/ui/InputBox.gd`, replacing the `_last_draft` field and the three functions that touch it; `_draft_peak` holds the longest text seen since the last clear):

```gdscript
var _enabled := true
var _draft_peak := ""


func clear_draft() -> void:
	text = ""
	_draft_peak = ""


func _on_text_changed(new_text: String) -> void:
	if new_text.length() >= _draft_peak.length():
		_draft_peak = new_text
	if new_text.is_empty() and not _draft_peak.is_empty():
		# The signal carries the whole erased draft for M21: backspace erases
		# one character per edit, so the last edit only knows the last char.
		draft_deleted.emit(_draft_peak)
		_draft_peak = ""
	draft_changed.emit(new_text)


func _on_text_submitted(raw: String) -> void:
	var trimmed := raw.strip_edges()
	if trimmed.is_empty():
		return
	text = ""
	_draft_peak = ""
	submitted.emit(trimmed)
```

(`_last_draft` then becomes unused and should be deleted with its remaining references. An equivalent fix is to have `ChatUI._on_draft_changed` forward the text and let `Telemetry` track the peak, but the sender owns the "carries the last words" contract, so `InputBox` is the narrower change.)

## Summary

The seam itself is faithful: all seven detectors normalize to one event, reach `Triggers` in real time, land in `ctx["events"]` at the docs/02 §4 step 0 that P1.08 had silently broken, and the deleted draft is genuinely memory-only — quoted once into the prompt, scrubbed out of the transcript, absent from saves, gone after use. The blocker is the draft detector's real-world coverage: because `InputBox` emits only the text before the *final* edit, a draft erased with backspace arrives as one character and is dropped by `draft_min_chars`, so M21 never fires for the ordinary delete gesture (P2.09-DES-1). Two smaller design drifts (a duplicated draft line, an "in a row" claim the window does not support) and one dead store are listed for the fix round; the 15-autoload DCR is supported.
