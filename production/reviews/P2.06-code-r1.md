## Summary

The corruption filter is a clean, well-factored pure core plus a small streaming adapter: gates are enforced as code, the per-stage plans are pinned by exact-string tests, the RNG is derived per (turn, beat, effective stage) in a fixed order, and I could not break the chunk-boundary invariant — one chunk, char-by-char, and `transform_beat()` all produce identical text across stages, seeds, whitespace and unicode inputs, with reduced motion removing exactly the glyph effects and calmer exactly reproducing the stage-3 plan. The seam order is right (Safety → corruption → typewriter), the flush tail introduces no unscanned text, and refusals are byte-identical to what the Safety path wrote. No S1/S2 issue: the findings are two S3s (protections that are documented as code rules but read verbatim from data; the Director replay stub never starts a UI turn, so replays are filtered at the stale stage/seed) and four S4 nits, all with small, contained fixes.
