| CODE-1 | S1 | `game/tests/MetaEventsM31Test.gd:285, 33-40` | Test state leakage in `after_test()` corrupts subsequent test suites in `tools/test.sh`. `test_the_sky_tint_is_skipped_for_photosensitive_players` invokes `_at(3, 0)`, setting `module._clock` to 3:00 AM. `after_test()` fails to restore `module.set_clock(Callable())`, `module.user_root = "user://"`, or reset session state. Because `MetaEventsM31` is a child node of autoload `MetaDirector`, subsequent test suites run with a 3:00 AM clock, triggering M36 (3 AM) on any `offers(4)` call, which spends the scene budget and triggers `never_two_in_a_row`, causing 12 test failures and 5 runtime errors. | In `MetaEventsM31Test.gd:after_test()`, restore `module.set_clock(Callable())`, `module.user_root = "user://"`, and call `module.begin_session()`. In `MetaEventsM31.gd:_on_state_reset()`, defensively reset `_clock = Callable()` and `user_root = "user://"`. |
| CODE-2 | S1 | `game/autoload/MetaDirector.gd:228` | Querying `offers(stage)` triggers unrequested side-effecting scripted events and pollutes `session_log()`. Calling `offers()` runs `_roll_scripted(stage)`. If `_greeting_due` is true, M35 fires and appends to `_session_log` and `meta_seen`. This breaks the contract of `offers()` (which should query available offered actions) and breaks existing tests `MetaSchedulerTest.gd:test_execute_counts_the_event_and_tells_her` and `MetaHardRulesTest.gd:test_hard_rule_5_every_fired_event_is_logged_for_extras` where `session_log().size()` is unexpectedly 2. | Do not execute scripted rolls during `offers()`. | CODE-3 | S2 | `game/llm/meta/MetaEventsM31.gd:282-297` | Memory leak: orphan nodes in `build_extras_section()`. `box := VBoxContainer.new()` and `title := Label.new()` are allocated prior to checking `has_notes()`.
