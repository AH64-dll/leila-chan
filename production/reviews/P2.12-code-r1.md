### CODE-1 — ordinary caring lines are scored as apathy (and as ignoring her) (S2)

`_is_apathy()` (`ProfileKeywords.gd:131`) returns `true` on its first branch whenever `_has_any(text, rule["phrases"])` matches; only the second branch (the ≤`short_reply_words` path) honours "asks nothing". `_has_any()` (`:148`) matches a data phrase anywhere in the message as a whole word. `classify()` reuses the returned `dismissive` for `ignored_questions` (`:87`, `:96-97`), so one matched word can move two counters at once.

Reproduced (probes above; `last_question` = "Do you love me?"):

- "Are you sure you're okay?" → `apathy 1`, `ignored_questions 1`. A 4-word caring question is neither "a dismissive phrase" nor a ≤2-word reply, and it cannot be "ignoring her direct question" (docs/01:165, T15).
- "I'm not sure what you mean." / "That's fine, I understand." / "Cool, let's go." / "I don't care about her, I care about you." → `apathy 1` (+ `ignored_questions 1`), from `sure` / `fine` / `cool` / `don't care` inside a sentence.
- Through `GameState.apply_turn_profile()` one such line wrote `HOLLOW = 2.0` and stamped `path_evidence["HOLLOW"] = 1` on a fresh state — exactly the score the path is selected from and the recency the tie-break reads.

Impact: `2·apathy + coldness + ignored_questions` means one caring question can be +3 HOLLOW. At Stage 2 that can decide the path; at Stage 3 the wrong path locks permanently. Depending on the model's `read`, the same turn can also add `warmth`/`honesty` (e.g. `affection`), so one line can move the profile in opposite directions.

The data file's own contract says `apathy = a dismissive phrase, or a reply of at most short_reply_words words that asks nothing and is not exempt` — i.e. the *message* is a dismissal. A question containing "sure" is neither branch.

```gdscript
func _is_apathy(raw_text: String, text: String, rule: Dictionary) -> bool:
	# docs/01 §4.4 + the data contract: a dismissal asks nothing. A question is
	# never one, whatever word it happens to contain ("Are you sure?").
	if raw_text.contains("?"):
		return false
	if _has_any(text, rule["phrases"]):
		return true
	var cap := int(rule.get("short_reply_words", 0))
	if cap <= 0:
		return false
```

Then remove the ambiguous single-word entries from `game/data/profile_keywords.json` (`bored` `:35`, `sure`/`fine`/`cool` `:37-39`, `ok`/`okay`/`k`/`mhm`/`hm`/`lol` `:40-45`): the ≤2-word rule already catches them when they stand alone, so containment can only fire on the distinctive phrases (`whatever`, `idk`, `dunno`, `meh`, `nothing much`, `don't care`, …). Add a caring-question and a warm-line case to `ProfileKeywordsTest` (and one path-level assertion that such a line leaves HOLLOW at 0).

### CODE-2 — the exempt-courtesy check is prefix-based, not word-based (S3)

`text.begins_with(phrase)` only exempts a line that *starts* with a courtesy. The data exempts `sorry` (`profile_keywords.json:63`), yet the natural apology "I'm sorry" starts with "i'm" and is scored as apathy — plus `ignored_questions` when she had asked something (probe: `apathy 1, ignored_questions 1`). Conversely "nothing" starts with "no" and "him" with "hi", so both are wrongly exempt (probe: `{}`).

```gdscript
	for exempt: Variant in rule["short_reply_exempt"]:
		var phrase := _normalise(str(exempt))
		if not phrase.is_empty() and _has_any(text, [phrase]):
			return false
```

### CODE-3 — generic control phrases fire on ordinary sentences (S3)

The file defines `control` as "the player orders her around", but under whole-word containment `you will`, `you must` and `i said` match ordinary sentences: "You must be tired." → `control 1`; "I said I'm sorry." → `control 1` (a player apologising); "You will be fine." → `control 1` and `apathy 1` (from `fine`). Unambiguous imperatives already in the list (`do as i say`, `obey me`, `sit down`, `be quiet`, `answer me`, `look at me`, `come here`, …) carry the signal without the false positives.

Suggestion: delete `you will` (`:6`), `you must` (`:7`) and `i said` (`:21`) from `game/data/profile_keywords.json`, or replace them with whole imperative phrases.
