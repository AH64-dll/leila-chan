## Judgment: `get_stage()` removal (`AudioDirector.gd:282-285`)
Accepted, not a finding. `grep` over `game/` finds no remaining caller — the accessor was used only by
`DirectorRoutingTest.gd`, which now proves the stage hand-over behaviourally (`:426-440`: `sob`'s gate is 1, so a stale stage 0
denies `gated` while a handed-over stage 1 fails later on its documented `gap`). `_stage` stays internal, which matches
protocol §"autoloads talk via signals and narrow APIs", and the only UI consumer (`DebugOverlay`) refreshes from
`music_changed`/`cue_played`/`cue_denied` without reading the stage. The cost is that `AudioDirector` now sits at exactly
`max-public-methods: 20` (`gdlintrc`), so the next public entry point has no headroom: the producer should decide now whether
the voice-blip API moves into a child node or the cap is raised deliberately (the test suites already split at the cap).
