## Findings

| ID | Sev | Where | Problem | Suggested fix |
|---|---|---|---|---|
| CODE-1 | **S1** | `game/autoload/SaveSystem.gd:496-503` | `_recurse_wipe` normalizes its root with `dir_path.trim_suffix("/")`. For the shipped default `user_root = "user://"` (`:77`) that yields `user:/`, `DirAccess.open` returns null and the function returns without deleting anything, so `Settings.reset_everything()` → `wipe_everything` (`:135-140`) reports `ok: true, removed: 0` and every personal file survives — shadow save, slots, letters, diary. Acceptance criterion 2 is met only in the test's scratch root; the trim is also unnecessary, because the top-level root is never passed to `DirAccess.remove_absolute` (only `path_join`ed children are). | Normalize without eating the scheme (below), extract it as a helper and pin the helper in `ShadowSaveTest`: `assert_str(SaveSystem._wipe_root("user://")).is_equal("user://")` and `_wipe_root("user://scratch/") == "user://scratch"`. See the code block under the table. |
| CODE-2 | S3 | `game/llm/ShadowStore.gd:188-201` | `_heal` is the guard for a hand-edited file, but it only type-filters: it does not apply either documented cap, so a `shadow.json` with 10 000 `memories` reads back as 10 000 (probe case 8) and `runs` longer than `RUN_LIMIT` survives a read. `MemoryStore.from_dict` (`game/llm/MemoryStore.gd:238-252`) is the established pattern in this codebase and trims an over-capacity save by the same eviction rule a live store uses; `shadow_memories()` (`SaveSystem.gd:120-121`) hands its result straight to a future prompt (P3.09) with no cap of its own. | Apply the documented caps in `_heal`: `record["runs"] = runs.slice(maxi(0, runs.size() - RUN_LIMIT))` and `record["memories"] = memories.slice(0, maxi(0, MemoryRules.shadow_memory_limit()))`. |

### CODE-1 fix

```gdscript
	# A trailing "/" stops DirAccess.remove_absolute() from removing a child
	# built from that path, so normalize it — but never strip the scheme:
	# "user://" must stay "user://", or DirAccess.open() cannot resolve it and
	# the wipe silently deletes nothing.
	var root := dir_path
	while root.ends_with("/") and not root.ends_with("://"):
		root = root.trim_suffix("/")
	var dir := DirAccess.open(root)
	if dir == null:
		return
```
