### CODE-9 — the OPPORTUNITY sentence outlives the offer it explains

`MetaDirector.offers()` (`game/autoload/MetaDirector.gd:93-97`) is called by the turn path after the submit has already
drained the queue: `Director.submit_player_input` takes `GameState.pending_events` at `game/autoload/Director.gd:307`, then
`_start_turn` calls `MetaDirector.offers(stage)` at `:388`, before `build_turn_context` at `:391`. The sentence queued by
`offers()` therefore rides the **next** submit — which is what makes every open turn carry it (probe:
`open-turns(line,offered)=[[true,["refuse_exit"]],[true,["refuse_exit"]],[true,["refuse_exit"]]]`). But when the model
accepts the offer, `Director._close_turn_success` calls `MetaDirector.execute_after_text("refuse_exit")` (`Director.gd:767-768`),
which reaches `_close_offer()` (`MetaDirector.gd:162-166`); that only flips `_offer_open`, so the copy queued at `:388`
stays in `GameState.pending_events`. The next submit drains it (`Director.gd:307`) into the prompt while `offers()` now
returns `[]`, so the model reads "The player just tried to close the window. You may set action to refuse_exit…" on a turn
where neither is true and the schema's enum is `["none"]` (probe: `after-consume stale_line=true offered=[]`). This is
docs/05 §2's "(only on turns with an offer)" broken on the turn after the refusal, i.e. the mirror of round 1's DES-4 and
on the offer's success path, not a rare edge.

The new test cannot see it: `test_close_offer_line_rides_every_turn_of_the_offer`
(`game/tests/TriggersT09T15Test.gd:256-271`) drains the queue at `:265` and `:267` *before* it consumes the offer at
`:269`, so its "A consumed offer stops both the action and its sentence" assertion (`:270-271`) runs against an empty
queue and passes no matter what `_close_offer()` does.

Fix (three lines plus one test step): drop the sentence when the offer closes, so `reset_session()` also cannot carry a
dead offer line into the new session —

```gdscript
func _close_offer() -> void:
	if not _offer_open:
		return
	_offer_open = false
	GameState.pending_events.erase(_opportunity_line())
	offer_changed.emit()
```

and in the suite, after `MetaDirector.offers(3)` queues the line, call `execute_after_text("refuse_exit")` without
draining first, then assert `GameState.pending_events` does not contain it.

I keep this at S3 rather than S2 for consistency with round 1's DES-4 (same docs/05 §2 sentence, same class of prompt
drift, no state or safety impact — the enum still makes the action unselectable). The producer may escalate it; if the
fix lands, no other change is needed.

### CODE-10 — the flags-copy comment now states the opposite of the `observe` contract

`Triggers._context()` builds the engine's snapshot with a duplicated `flags` dictionary and says
"a fire during this turn must not change what a later row's clock detector sees inside the same evaluation"
(`game/autoload/Triggers.gd:246-248`). The new `_observe()` writes into exactly that copy
(`game/llm/TriggerEngine.gd:284-285`, "this turn's later rows"), and that write is what stands T04 down on a Day-12
confession — remove it and CODE-1 comes back for the same-turn case the round-2 test at `TriggersT01T08Test.gd:118-124`
covers. The comment now documents the invariant the fix intentionally breaks, and a future "restore the isolation" edit
would pass review by reading it. One sentence is enough: say the copy isolates *fired effects*, and that `observe` is the
one deliberate same-turn write (which is also why the T03 → T04 order in `triggers.json` matters).
