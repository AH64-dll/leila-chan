### CODE-8 — a corrupt save with a wrongly-typed field wipes the store

`from_dict()` is the P2.11 contract with P2.20, and the r2 comment above it says the function is "only its input guard". In practice it guards the *shape* (`rows is Array`, `row is Dictionary`, empty text) but not the *types* of the values it reads. GDScript's `int()`/`float()`/`String()` are constructors, not `str()`-style conversions: on a Variant holding a container or null they raise and the call unwinds. Since `reset()` runs first, the store is left with whatever rows were appended before the bad field — none, for a bad `capacity`, `seed`, `state` or first `text`.

```text
>> IMPORTANCE_DICT
SCRIPT ERROR: Invalid call. Nonexistent 'float' constructor.
          at: MemoryStore.from_dict (res://llm/MemoryStore.gd:238)
<< IMPORTANCE_DICT size=0 imp=[]
```

Severity is S3 rather than S1 because there is no production caller yet (grep: the only references to `Memory.to_dict()`/`Memory.from_dict()` are the facade in `game/autoload/Memory.gd` and the tests) and the handoff explicitly defers corrupt-save *handling* to P2.20. The code comment and the `test_store_save_round_trip…` claim ("a corrupt save cannot break the two invariants") should not outrun the implementation before P2.20 starts.

### CODE-9 — the replayed turn's `memory` block is not its own

The r2 fix states the invariant "the transcript's memory block is this turn's only" (`Director.gd:366`). Every record written from a live turn honours it — `_start_turn()` opens the record and `_reject_unsafe_input()` opens it explicitly — but `replay_turn()` builds its state by hand and goes straight to `_on_llm_completed()`, so it never opens one. `note_quotes()` clears `last_quotes` and `consider()` overwrites `last_proposal`, so only `last_corruptions` is left stale, and that list is cleared by `begin_turn()`/`prompt_facts()` alone. The one-line fix costs nothing and keeps the invariant literal.
