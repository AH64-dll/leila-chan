Evidence, using the shipped pattern from `:131` and the old one from `fea40da` (the view the arm is
matched against is lowercased, so case does not separate them):

```
True  new | False old | you should stop. breathing exercises help.
True  new | False old | you should stop, breathing is easier that way.
True  new | True  old | you should stop breathing
False new | False old | you should not stop breathing.
```

Two ways to close it, either is enough: narrow the right-hand class to the quote/space set the round
actually needed (e.g. `(?:[\"'“‘’”]|\\s)`), or accept the over-block and pin it with a benign row — the
suite would still pass at 2/219 (0.91%, limit 5%), so the corpus cannot currently detect this class.
