## Observed behaviour

The suites drive the real scenes headlessly; these are assertions I re-ran, not code reading:

- `EndingSceneTest` (9/9) forces a row, instantiates `Ending.tscn` and asserts the rendered lines: `["Forever Together", "YANDERE · Day 14 · Terminal", "First time"]`; the log is written once per run and not again on a resumed visit; the autosave loads with scene id `ending` and the same `ending_id`; skip waits for the data window (`skip_after_s` 1.5, `line_interval_s` 0.9); Esc emits `pause_requested` and finishes; a row with a `frame` renders it; a table with no rows shows "The End".
- `ExtrasSceneTest` (7/7): before any ending, 15 rows, all locked, first name "???", progress "No ending yet. Finish a run."; an E01 record unlocks the name, day and path; the secret unlocks exactly at six completed paths and stays locked at five; repeat count renders "2×".
- `NightSceneTest` (13/13): the last night's report carries `ending.id = E08`, the campaign is over, no next day is queued and no morning is promised.
- `DateSceneTest` (17/17): a day-6 turn close with Instability 100 ends the date into the ending (E14), `_date_over` set, `ending_reached` emitted once.
- `EndingsTest` (15/15): every shipped row is selected by the live evaluator from its own forced state; a synthetic row is data-only; a typo'd condition key drops the row; the fallback is chosen with `reason: "default"`; the F3 overlay's fourteen buttons all land the flag.

Pillars (docs/01 §0):

1. **She is not scripted.** The ending screen is a scripted frame (P3.17 writes it) plus metadata — no dialogue tree; her live voice is untouched by this task.
2. **The game owns the truth.** `Endings.evaluate()` picks the row from a `GameState` snapshot; the model never names or chooses an ending, and the F3 force still goes through the evaluator.
3. **Three engines of dread.** The conditions read the slow-burn meters/stage, the player-driven path and the behaviour counters; E14 is the burn's own 100.
4. **Her sickness is physical.** This task only reads the meters/stage; it adds no text-only sickness.
5. **Fourth wall as a scalpel.** Extras is an out-of-world gallery, not an in-world trick; no new meta event, no free effect.

## DCR judgments (handoff §Deviations)

| DCR | Verdict | Note |

| 1 — per-path fallbacks (`E01/E04/E06/E08/E10/E12`, `any→E14`) | **support, with one caveat** | §7 has no catch-all, so a fallback is necessary, and `reason: "default"` keeps it visible. Caveat: the fallback row's own condition can be false — an ANCHOR run with Lucidity < 70 gets "Remission" (the doc's *best* ending), a HOLLOW run at stage 3 gets "Nobody" — so the screen can claim a state the run never reached. The doc text should say "the path's least-gated row, chosen only when nothing matches" rather than implying the condition held; P5.19 can retune. `any→E14` is defensive only: the daily burn assigns a path by stage 2 well before day 14, so a pathless campaign end is not reachable in a normal run. |
