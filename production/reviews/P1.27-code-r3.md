This is a wording nit, not a behaviour bug — the code and tests demonstrably do the right thing. | Consider one clarifying clause: "between `cancel()` and terminal delivery, `is_cancelled()` may be true before the terminal signal fires; consumers must gate on the terminal signal, not `is_cancelled()`." |
