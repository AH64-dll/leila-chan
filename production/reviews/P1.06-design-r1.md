## Pillars (docs/01 §0)
1. **She is not scripted** — the builder invents no dialogue; all voice text comes from data files or `ctx`. The only generated line beyond the doc-verbatim player/memory headers is the offered-enum summary, which the schema also constrains. **Pass.**
2. **Game owns the truth, model owns the voice** — the builder is a pure function of `ctx` (purity is tested: `test_build_is_pure_and_repeatable` asserts the input dict is unmodified, identical output on repeat and after `clear_cache()`); it emits suggestions-free structure only. **Pass.**
3. **Three engines of dread** — event lines are pass-through; trigger timing stays with the Director (P1.08). **Pass (n/a in scope).**
4. **Sickness is physical** — no steering dose touches the prompt text itself; dose enters at decode (docs/02 §4 step 4), consistent with the design. **Pass (n/a in scope).**
5. **Fourth wall as a scalpel** — the builder cannot offer `action` values of its own; `offered` comes only from `ctx` (P1.07/P1.08 own the gate tables). An empty `offered` yields no fourth-wall line. **Pass.**

Later-phase dependencies noted: P1.07 supplies `ctx.offered` so prompt and grammar agree by construction; P1.08 owns `ctx` resolution and must write history through `spoken_text()` to keep the plain-text rule true at the source; P1.18/P1.20 consume `debug` (JSON-safe) and can inject a real tokenizer; P2.11/P2.13 own corruption and the stage 2–5/path modules.
