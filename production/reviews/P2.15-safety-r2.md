## Residual risk (not findings — disclosed and producer-owned)
1. **The safe mode is opt-in and there is still no first-launch notice.** A player who does not toggle the Title row sees the 4-flash/0.63 s strobe at stage 3. This is the design's reading of docs/02 §2.3 (a "photosensitive-safe mode", not a default) and the handoff explicitly defers the flashing-lights notice to the P3.13 content-warning work. If the producer wants "no >3 Hz content in any default path", that is a design decision/DCR (cap `FX_FLICKER_STEPS` or default `photosensitive` on), not a silent code change.
2. **No mid-date surface yet.** Toggling during a date needs the pause menu (META); `Settings.set_photosensitive` is already safe to call mid-cue, so the future UI is a one-liner.
3. `load_settings` fails open to Off on a corrupt file without a warning (case 7 above). Worth a `push_warning` when P3.13 owns more settings keys.
