### P2.09-CODE-1 replacement — `game/scenes/ui/InputBox.gd`

`_draft_peak` holds the longest text seen since the last clear; the deleted-draft signal then carries the whole erased draft, not the last character. `_last_draft` becomes unused and is removed with its three references.

```gdscript
var _enabled := true
var _draft_peak := ""


func clear_draft() -> void:
	text = ""
	_draft_peak = ""


func _on_text_changed(new_text: String) -> void:
	if new_text.length() >= _draft_peak.length():
		_draft_peak = new_text
	if new_text.is_empty() and not _draft_peak.is_empty():
		# The signal carries the whole erased draft for M21: backspace erases
		# one character per edit, so the final edit only knows the last char.
		draft_deleted.emit(_draft_peak)
		_draft_peak = ""
	draft_changed.emit(new_text)


func _on_text_submitted(raw: String) -> void:
	var trimmed := raw.strip_edges()
	if trimmed.is_empty():
		return
	text = ""
	_draft_peak = ""
	submitted.emit(trimmed)
```

`test_chatui_forwards_drafts_and_turn_state` currently goes straight from a full draft to `""`; add the per-character case (emit `text_changed("hell")`, `("hel")`, `("he")`, `("h")`, `("")`) and assert `draft_pending` plus the staged quote carry `"hell"`.

## Summary

The seam itself is sound and verified: all seven detectors normalize to one event shape, reach `Triggers` in real time, and land in `ctx["events"]` at the docs/02 §4 step 0 that P1.08 had broken; the deleted draft is genuinely memory-only — quoted once at stage ≥ 3, scrubbed out of the dev transcript, absent from saves, and gone after the turn. The blocker is detector coverage: `InputBox` reports only the text before the final edit, so a draft erased with backspace arrives as one character and is dropped by `draft_min_chars`, meaning T08/M21 never fires for the ordinary gesture (P2.09-CODE-1). Three smaller issues (a duplicate draft line, an "in a row" claim the window does not support, and a privacy assertion that can pass vacuously) and two dead-code nits are listed for the fix round.
