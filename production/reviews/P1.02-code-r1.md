## P1.01 CODE-2 carry-over (cooperative cancel + bounded teardown)

- HTTP: `LlamaHttpClient.gd` has a connect timeout (2s), a read timeout (60s idle), and a turn timeout (180s whole-turn hard cap; the write loop is also turn-bounded) — all poll the cancel token, and the `POLL_MS=2` loop means a cancelled turn returns within one `%POLL_MS` delay.

The one tool oddity worth reporting: on this Linux box every `_stop_locked` (test teardown, demo shutdown) reaches `OS.kill(pid)` on a dead pid and prints `ERROR: The process NNN does not exist or is not a child of the calling process.` Godot's `OS.kill` checks `pid` liveness *before* issuing the syscall and errors when already gone. A dir check (`OS.is_process_running` first) removes the noise; noted as CODE-2.
