## Pillars

1. **She is not scripted** — the diff adds no line or frame; it selects existing art from data. ✔
2. **The game owns the truth, the model owns the voice** — every rule (pools, whiplash pair, break, drift, healthy column, spikes, recovery) is a `casting.json` key read by game code; nothing comes from the model. ✔
3. **Three engines of dread** — path rules key off stage tiers and beat valence; the two beat flags are meant to be game-set spikes. The "who sets them" gap is DCR 4's follow-up, not a design weakening. ✔
4. **Her sickness is physical** — the path faces are a function of stage/tier and the corrupt sprite band; ANCHOR explicitly resolves from the pre-fracture column, so corruption is visible as a *difference* from it. ✔
5. **Fourth wall as a scalpel** — untouched by this task; no AWAKE change beyond the pre-existing shader hook. ✔
