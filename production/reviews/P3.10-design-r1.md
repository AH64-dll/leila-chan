## Observed behaviour

1. **M22 Typing and deletion:**
   Ran `MetaUIEventsTest.gd::test_m22_the_player_can_delete_every_character_she_typed`. The input box receives her suggestion, character by character (`MIMIC_CHARS_PER_SECOND = 30.0`). Backspacing or typing cancels her typing immediately and leaves whatever characters remain in the box. Nothing is submitted until the player presses Enter.
2. **M25 UI Hide and Click Restore:**
   Ran `MetaUIEventsTest.gd::test_m25_hides_every_box_and_a_click_brings_them_back`. Calling `apply_meta_ui("hide")` hides the text box, chat log, and input box. A single left click restores all boxes and re-focuses the input box. Esc opens the safe pause menu without impediment.
3. **M23/M24 Log Edits and Extras Reversibility:**
   Ran `MetaLogEditsTest.gd::test_extras_lists_the_rewrites_and_restores_them`. A player line "I like you" is rewritten to "I love you". The chat log renders the lie, but `ChatLog.get_entries()` retains "I like you". In the Extras menu, the row is displayed: `You wrote: "I like you" — the log reads: "I love you"`. Clicking "Restore my words" removes the edit, restoring the chat log display to the player's true words.
4. **Spent M23 Starvation Probe:**
   Inspected `MetaEventsM21.gd:_due_scripted`. In a stage-4 date scene on the SPLIT path where M23 has already occurred, M23 rolls `true` (35% probability). `_due_scripted` returns `M23` without checking if it is already in `events_seen()`. `MetaDirector` rejects M23. M24 and M26 are completely skipped for that turn.

## Pillars (docs/01 §0)

1. **She is not scripted** — Meta events offer actions or trigger diegetic UI glitches, but dialogue remains generated by the model.
2. **The game owns the truth, the model owns the voice** — Chat log entries keep the true player text; model suggestions are non-destructive and editable.
3. **Three engines of dread** — Meta events M21–M26 escalate from subtle draft recognition (M21) to input corruption (M22) and history rewriting (M23/M24).
4. **Her sickness is physical** — The visual corruption of the UI matches her stage progression; however, DES-2 allows stage-4 log corruptions to leak into stage-0 New Game runs.
5. **Fourth wall as a scalpel** — UI vanish and slider tampering are rare, capped, and immediately reversible.

## Summary

The design fidelity of M21–M26 is generally strong: the player maintains complete agency over the input box during M22, M25 UI hide is strictly temporary and restores on any input, and M23/M24 log rewrites preserve the player's true words behind a reversible display filter. However, two S2 design issues must be addressed: (1) `_due_scripted()` does not check if an event is already seen, allowing a spent M23 to starve M24 and M26 on 35% of eligible turns; and (2) `MetaLogEdits` leaks previous run rewrites into fresh New Game campaigns, corrupting Stage 0 dialogue. Additionally, uncommitted worktree changes and a missing handoff report block merge. Verdict: CHANGES_REQUESTED.
