## Findings
| ID | Sev | Where (file:line) | Problem | Suggested fix |
|---|---|---|---|---|
| CODE-1 | S3 | `game/autoload/LLM.gd:97-98` | Any `error` value that is a Dictionary is forwarded verbatim as the terminal `failed` payload. A backend returning `{"ok": false, "error": {}}` (or an error dict without a String `code`) emits `failed({})`, so callers that read `error.code`/`error.message` get null, while every other malformed result is normalised to `{"code": "malformed_result", ...}`. The contract documents `{code, message}`, but the facade's own "malformed" normalisation is bypassed for this shape. | Require `error.get("code") is String` before forwarding (fall back to `malformed_result` otherwise) and add one case to `LLMTest.gd`. |
| CODE-2 | S4 | `game/autoload/LLM.gd:162-174` | `_shutdown()` waits unbounded on the active worker. This is correct at teardown provided the backend honours the `LLMBackend` contract ("poll cancel and return promptly"), but a backend stuck in a network read would hang game quit. | Optional hardening: state a maximum wound-down time in the `LLMBackend` contract and have P1.02 enforce an HTTP timeout so this join is bounded; no change needed in the facade. |
| CODE-3 | S4 | `game/autoload/LLM.gd:56-57` | `generate()` freezes the facade dose by writing into the caller's `TurnRequest.dose`. If a caller reuses one request object across turns, later `set_dose()` values are silently ignored (the dose is no longer empty) — and it contradicts the `TurnRequest` docstring's "treated as immutable once passed to LLM.generate()". The handoff documents the freeze, but not single-use requests. | Document `TurnRequest` as per-turn/single-use, or keep the frozen dose beside the request instead of mutating the caller's object. |

Severity: S1 blocker · S2 major (must fix) · S3 minor (fix or ticket) · S4 nit (optional).
