## Observed behaviour (round 2)

1. **Starvation probe closed:** `MetaEventsM21._due_scripted()` (`:226-240`) iterates `SCRIPTED_ORDER` and now skips any id failing `_allowed_here(id, stage)` before rolling. `_allowed_here` (`:304-308`) delegates to the host's `_scripted_allowed`, which is the same gate `_fire_scripted` applies — so proposal and charge can no longer disagree. `MetaScriptedEventsTest::test_spent_m23_does_not_starve_m24` reproduces the r1 scenario exactly (M23 in `meta_seen`, both chances at 1.0) and M24 now lands.
2. **Run isolation:** `MetaLogEdits.clear()` removes both the in-memory rows and the on-disk ledger. `NewGame.gd` calls `SaveSystem.begin_new_game()` then `GameState.reset()` — both clear, idempotently. Save-load goes through `GameState.from_dict`, which does not clear, so a mid-run save still renders her version after reload (the documented behaviour). A fresh Stage-0 run can no longer inherit "I love you" for "I like you".
3. **Determinism:** `record()` timestamps come from `_now()`, which uses the injected `_clock` when set — same seam shape as `SaveSystem._clock`/`EndingLog.set_clock`.
