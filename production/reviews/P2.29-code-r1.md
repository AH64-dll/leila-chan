## Findings

| ID | Sev | Where (file:line) | Problem | Suggested fix |
|---|---|---|---|---|
| CODE-1 | S3 | `game/tools/full_run_driver.gd:257-260, 799-801` | Stale transition relaunch reporting and overwrite race. In `_on_stage_transition`, `trans["relaunch"] = _last_steering_info.duplicate(true)` is executed without checking whether `_last_steering_info.get("stage")` matches `current`. On stage transitions after the first (e.g. stage 1→2), `_last_steering_info` holds the previous stage's report; if stage 2 has identical vectors (no relaunch) or while the background relaunch thread is in flight, transition 2 falsely reports the old stage's relaunch data. Conversely, if `LLM.apply_stage_steering` fails synchronously, `_on_steering_applied` runs before `_on_stage_transition`, causing `_transitions[-1]["relaunch"] = info.duplicate(true)` to overwrite the prior transition's record with the new failure report. | In `_on_stage_transition`, only attach `_last_steering_info` if `int(_last_steering_info.get("stage", -1)) == current`. In `_on_steering_applied(info)`, search `_transitions` in reverse for the transition matching `int(info.get("stage", -1))` rather than unconditionally mutating `_transitions[-1]`. |
| CODE-2 | S3 | `game/tools/full_run_driver.gd:931-937` | Abnormal terminations misclassified as checkpoint summaries in `_finish_run`. The boolean expression `is_checkpoint` evaluates to `true` whenever `not _campaign_over and int(GameState.stage) < _stop_stage and not reason.begins_with("campaign ended")`. This causes premature aborts due to turn failures (`turn failed %d times in a row (%s)` at line 567) or scene stalls (`the date ended (%s) but the loop did not open Night` at line 971, `no Date or Night scene for %d s` at line 974) to emit `## Checkpoint summary` and `full_run: checkpoint — ...` with exit code 0 if `_broken` is empty, masking an engine stall or failure as an intentional segment checkpoint. | Restrict `is_checkpoint` to explicit day-cap stops (`reason.begins_with("day cap")`) or explicitly exclude failure reasons (`and not reason.begins_with("turn failed") and not reason.begins_with("no Date") and not reason.contains("did not open Night")`). |
