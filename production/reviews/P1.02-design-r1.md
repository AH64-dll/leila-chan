## Pillars (docs/01 §0) — one line each

1. **She is not scripted.** The transport is a content-free pipe and carries the request's own grammar: the model's lexicon is only constrained by the per-request schema (ints, enums) but not by any staged lines. **Untouched.**
2. **The game owns the truth, the model owns the voice.** The backend never applies model output to game state; it only surfaces chunks + metrics. Sampling, schema, dose come from the request, never hard-coded here (only sampling *defaults* exist). **Untouched.**
3. **Three engines of dread.** No staged pacing in this lane. `first_say`/`ttft` metrics objectively measure the slow-burn pacing logistics later passes tune. **Untouched.**
4. **Her sickness is physical.** Control-vector launch flags pass through `--control-vector-scaled` from config (P2.03 owns the dose schedule); the prototype's restart-at-stage-change is correctly prepared for but not yet consumed (correct scope boundary, not a pillar violation). **Untouched.**
5. **Fourth wall as a scalpel.** No meta or wall logic lives anywhere in these files. **Untouched.**
