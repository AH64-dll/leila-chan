## Later-phase dependencies (safety)

- **P3.09 must persist `meta_seen` before M02 ("she closes the game") quits.** `_fire()` writes the flag via
  `GameState.set_flag`, and `SaveSystem` only writes on a scene autosave; a quit that skips a save would let
  a `once_per_save` event replay on relaunch. P3.08 only records; the quit path is P3.09's.
- **P3.09/P3.10/P3.11 effects must re-check the §0 class themselves** (SAF-5 makes that a code backstop too):
  an `os_deep` action needs Deep at execution, a `write` action needs its declared `user://` target, and a
  `quit` action must never leave the window unclosable.
- **P3.13** owns the Immersion switch the R4 gate reads; until it exists the setting can only be changed by
  code, which is why SAF-5 is not reachable in a shipped build today.
- **P3.18** audits the full catalogue against docs/05 §0/§4; the class table
  (`ACTION_CLASS`) and the row vocabulary (`ROW_KEYS`) are the two places that audit should extend.
