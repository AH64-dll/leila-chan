## The Five Pillars (docs/01 §0)

1. **She is not scripted.** Respected. M31–M38 communicate state context via `EVENT:` lines delivered into the prompt context; the LLM articulates her reaction in character. Offline/empty fallbacks exist for resilience.
2. **The game owns the truth, the model owns the voice.** Respected. All notes on disk, save slot names, clock calculations, and memory parses are executed deterministically by engine code. Model text is clamped and safety-scanned.
3. **Three engines of dread.** Respected. M36 (3 AM) spikes instability (+3.0) and transitions audio to `music_box`, creating genuine diegetic dread during late-night play.
4. **Her sickness is physical.** Respected. Gates strictly reflect progression: letter at St 2, diary at St 3, save names & other player at St 4 / AWAKE.
5. **Fourth wall as a scalpel.** **Compromised.** By coupling ambient date atmosphere (M35 real clock greeting) with `_roll_scripted()` inside `MetaDirector.offers()`, the system fires ambient context as if it were a fourth-wall rupture, writing it into `meta_seen` and polluting the Extras review log.

## Judging DCRs

- **DCR-1 (Scripted events ride `turn_events()` rather than `GameState.queue_event()`):** **SUPPORT**. In P3.08, `queue_event()` suffered from single-turn lag because the queue drained at Step 0 before context assembly. Delivering the scripted EVENT note directly in `turn_events()` on the same turn matches the design intent ("she is told afterwards").
- **DCR-2 (M35 clock greeting is ambient and does not spend the scene cap):** **SUPPORT IN PRINCIPLE**. The clock greeting provides date setting atmosphere and should not starve the scene's single allowed fourth-wall beat. However, the execution must not record ambient context into `_session_log` as an earned meta event or side-effect during offer inspection.
- **DCR-3 (M33/M34 slot names stored in a ledger beside saves rather than rewriting save slot metadata):** **SUPPORT**. Preserves `SaveSystem` purity and avoids file corruption while fulfilling the fiction of her naming the slots.
- **DCR-4 (Deliberate omission of numeric date formats like `03/05` in birthday parsing):** **SUPPORT**. Ambiguous day/month ordering without locale data causes false birthday triggers; requiring explicit month names is safer and matches high narrative fidelity.

| DES-1 | S2 | `game/autoload/MetaDirector.gd:228` | Querying `offers(stage)` executes `_roll_scripted(stage)`, violating the contract of offer querying and causing turn-1 offer starvation. When `offers()` is called to inspect actions (e.g. in schema generation or tests), a scripted/ambient event is fired immediately. If a budgeted event fires, it advances `_last_event_turn`, which immediately blocks `_roll_schedule(stage)` on the same turn under "never two in a row". | Decouple scripted event scheduling from `offers()`. Roll scripted events at explicit turn boundaries (e.g., in `Director.gd` turn step) and keep `offers()` as a side-effect-free query of open action offers. |
| DES-2 | S2 | `game/llm/meta/MetaEventsM31.gd:600-605` | Diary in-memory fallback disables the M32 announcement event. When `_notes_store().write(rel, text)` fails (e.g. read-only folder), `_diary_pending = day` is skipped. Because `_diary_due(stage)` requires `_diary_pending > 0`, the announcement meta event never fires, violating the principle that accessibility fallbacks provide full narrative parity. | Set `_diary_pending = day` on both disk write success and in-memory fallback. |
| DES-3 | S3 | `game/autoload/MetaDirector.gd:798-825` | Ambient clock greeting (M35) recorded in `_session_log` and `meta_seen`. docs/05 §3 states the Extras menu lists every meta event seen so players can review them after credits.
