## Findings

| ID | Sev | Where (file:line) | Problem | Suggested fix |
|---|---|---|---|---|
| CODE-1 | **S2** | `game/llm/meta/MetaEventsM21.gd:223-234` (`_due_scripted`) | **Spent M23 starves M24 and M26.** `_due_scripted()` iterates `SCRIPTED_ORDER = ["M23", "M24", "M26"]` and returns the first matching dictionary. However, it does not check whether `id` was already seen (`_allowed_here(id, stage)` or `MetaDirector.events_seen().has(id)`). Once M23 has fired in a run (it is `once_per_save`), on every turn where M23 rolls `true` (chance 0.35 at stage 4 on SPLIT), `_due_scripted` proposes `{"id": "M23"}`. `MetaDirector._poll_scripted` calls `_fire_scripted("M23")`, which refuses because `events_seen().has("M23")`. Because `_poll_scripted` only takes one proposal per turn, M24 and M26 are completely starved and never evaluated on 35% of eligible turns. | In `_due_scripted(stage)`, add `if not _allowed_here(id, stage): continue` inside the loop before returning `{"id": id}`. |
| CODE-2 | **S2** | `game/llm/meta/MetaLogEdits.gd:83` | **Timestamp uses un-injected OS wall clock.** `"at": int(Time.get_unix_time_from_system())` accesses system time directly without an injectable clock seam (`set_clock(Callable)`). This violates the project determinism standard and differs from `SaveSystem`, `Triggers`, and `TranscriptLogger`, which all provide `set_clock` for reproducible tests. | Add `static var _clock: Callable = Callable()`, `static func set_clock(clock: Callable) -> void`, and use `_clock.call() if _clock.is_valid() else Time.get_unix_time_from_system()`. |
| CODE-3 | **S2** | `game/llm/meta/MetaLogEdits.gd:28-34,142-166` | **Log edits leak across New Game runs.** `MetaLogEdits` persists in `user://.leila/log_edits.json` and in static `_rows`, keyed only by `speaker_key\u001foriginal\u001foccurrence`. Neither `GameState.reset()` nor `SaveSystem.begin_new_game()` clears or resets `MetaLogEdits`. If a player finishes a run and starts a New Game, then types a sentence that was edited in the previous run (e.g. "I like you", occurrence 1), `ChatLog._render_entry` calls `MetaLogEdits.shown()`, finds the stale row from the old run, and renders "I love you" on Day 1 at stage 0! | Connect `GameState.state_reset` (or `SaveSystem.begin_new_game`) to clear `MetaLogEdits._rows` and remove/wipe `log_edits.json` on New Game, or key rows by run/save identifier. |
| CODE-4 | **S2** | `lila-wt/P3.10` worktree | **Uncommitted working tree changes, WIP commit message, missing handoff and journal.** The worktree has 3 unstaged files (`MetaEventsM21.gd`, `DebugOverlay.gd`, `MetaScriptedEventsTest.gd`), commit `d8674a4` is titled `P3.10: wip checkpoint (producer-forced, quota conservation)`, `production/handoffs/P3.10.md` does not exist, and `production/journals/P3/META.md` has no P3.10 entry. Violates `AGENTS.md` and `.claude/skills/leila-work-protocol/SKILL.md` §4–§5. | Commit all modified files with proper `P3.10:` summary message, generate `production/handoffs/P3.10.md` with verification logs, and append entry to `production/journals/P3/META.md`. |
| CODE-5 | **S3** | `game/llm/meta/MetaEventsM21.gd:297-302` (`_charge_fallback`) | **Standalone unmounted fallback delivers note a turn late.** If `MetaEventsM21` is run unmounted without `MetaDirector._fire_scripted`, `_charge_fallback` calls `GameState.queue_event(note)`. `Director` drains pending events at step 0 before turn building, causing the note to ride the next turn instead of the current turn (the exact flaw fixed in P3.08 r2). | Feed notes via same-turn context or document that `MetaEventsM21` requires `MetaDirector` hosting. |

## Summary

The implementation of the M21–M26 meta events is structurally well designed: M22 allows continuous player editing and backspace deletion; M25 properly hides the UI and restores on any click or keypress without blocking Esc; and M23/M24 log edits are non-destructive and cleanly reversible from the Extras menu. However, the branch cannot be approved in its current state due to four S2 findings: (1) `_due_scripted` does not filter out already-seen scripted events, causing a spent M23 to starve M24 and M26 on 35% of eligible turns; (2) `MetaLogEdits` lacks an injectable clock seam; (3) `MetaLogEdits` leaks edits across New Game boundaries into fresh runs; and (4) the worktree was left with uncommitted changes under a WIP checkpoint commit, missing the required handoff report and role journal. Verdict: CHANGES_REQUESTED.
