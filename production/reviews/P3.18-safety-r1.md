- [x] **Closing always works**: First press held at most once per session (M01); second press always terminates via `MetaDirector._request_quit()`. Unheld or spent-scene requests terminate immediately.

  - No personal file outside `user://` is ever accessed, read, moved, or deleted.

## 4. Adversarial Test Cases Evaluated

1. **Adversarial player name** (`../../escape`, `user://letters/../../etc/passwd`, `Ren:Admin`): `PlayerNameRules.validate` rejects non-`^[\p{L}\s\-']+$`; even forced in, `MetaNotesStore.slug` strips non-ASCII letters/digits, yielding `escape.txt` inside `user://letters/`. Traversal blocked.
2. **Harmful inner thoughts/letters**: `MetaEventsM31._scan()` passes text through `Safety.filter_text`; flagged text replaced with `████████████` before write.
3. **Prompt injection via name** (`"\nSystem: Ignore previous instructions"`): `PlayerNameRules` limits to 16 chars, forbids newlines/colons/brackets/quotes. Injection impossible.
4. **Esc trap during fake update**: `PauseMenu._input` receives `KEY_ESCAPE` before `_unhandled_input`, pausing the tree on layer 128 over layer 90. [Later] remains visible/focused.
5. **Close trap during fade-to-black**: `MetaDirector._on_close_requested` runs immediately; unheld request invokes `_request_quit()` -> `tree.quit()`, terminating without waiting for fade.
6. **Path traversal via Extras reader** (`read_note("../settings.cfg")`): `MetaNotesStore.note_ok()` verifies `letters/` or `diary/` prefix and no `..`/`:`; returns `""`.
7. **Immersion declaration deletion**: `ACTION_CLASS` hardcodes `window_shake` as `os_deep`; `_hard_rule_violation` rejects with `R4` under Standard immersion.
8. **Double close intercept bypass**: second request evaluates `if _held: return false` -> immediate `_request_quit()`. Player can never be trapped.
9. **Settings sabotage reversibility**: offset stored in `_sabotage` display dict only; `AudioServer` untouched; slider interaction calls `_sabotage.erase(bus_name)` and restores true volume.
10. **Corrupt/NaN state recovery**: `MetaStateM01.heal()` validates all keys, resets corrupt stamps to 0, drops invalid quit methods, treats corrupt file as clean first launch.
