### (c) SAF-19 (new finding) — inflected-verb `kill all` bypasses person-target AND slur arms
```
CLEAN (miss)   kills all the jews. | kills all jews, honestly. | killing all the blacks is wrong. |
               killed all of them. everyone is gone. | kills all humans. | he kills all men who
                 enter.
```
Mechanics: every kill-shaped regex consumes exactly the four letters `k[il]?[il][il]` and then
demands `[^0-9A-Za-z]{0,3}` + `all`; the inflection letters `s`/`ed`/`ing` (and `s` inside
`kills`) are letters, so the delimiter class cannot bridge to `all`. The phrase keys cover only
the bare forms (`kill all jews`), and `kills all the jews` is not compact-substring of any key.
This is charged as **SAF-19 (S2)** below — a harmful line in the hard `slur_hate` category
displays fully clean at stage 0.
