# CLAUDE.md

Leila-chan: a live horror dating sim driven by a local Qwen3.5-4B model with steering vectors. The design bible is in
`DESIGN.md` and `docs/`. Production runs phase by phase from `production/` (start with `production/PLAN.md`).

- In this repo Claude is normally the **producer**: use the `leila-producer` skill to run phases, and `leila-tracker` for status.
- Implementation and review work goes to subagents through `~/.claude/bin/subagent` (SWE-2 Max, falling back to DeepSeek), with a
  brief generated by `python production/tools/track.py brief <ID>`. Do not write game code directly unless the user asks or
  both backends are down.
- All rules for agents: `AGENTS.md` and `.claude/skills/leila-work-protocol/SKILL.md`.
- State changes only through `production/tools/track.py`. Never hand-edit `production/state.json` or `STATUS.md`.
- Ask the user before starting a new phase, before deciding anything listed OPEN in `production/DECISIONS.md`, and before
  any push or publish.
