# AGENTS.md — rules for every agent working on Leila-chan

Leila-chan is a live, unscripted horror dating sim. A local Qwen3.5-4B model plays the heroine, and steering vectors make her
deteriorate. The design bible is `DESIGN.md` plus `docs/01`–`docs/10`. Production is run phase by phase from `production/`.

## If you were given a brief
1. Read the brief file you were given, completely.
2. Follow `.claude/skills/leila-work-protocol/SKILL.md`. It is mandatory for every implementer and reviewer.
3. Follow the role or review playbook the brief names (`.claude/skills/role-*/SKILL.md` or `.claude/skills/review-*/SKILL.md`).
   These are plain markdown files. Read them with your file tools even if your CLI doesn't support "skills".
4. Write your output where the brief says: a handoff in `production/handoffs/` (implementers) or a report in
   `production/reviews/` or `production/gates/` (reviewers).

## Never
- Edit `production/state.json`, `production/STATUS.md`, `production/phases/*` or `production/config.json` (producer only).
- Mark your own work done, merge branches, push to GitHub, or publish anything outside this machine.
- Commit model weights (`*.gguf`), llama.cpp binaries, the raw audio pool (`assets/audio/_raw/`) or secrets.
- Write to the `E:` drive (the read-only source of local artifacts; it is nearly full).
- Weaken the safety filter, the "closing always works" rule or the Esc safe pause (docs/02 §8, docs/05 §0).

## Layout
```
DESIGN.md, docs/          design bible (source of truth)
game/                     Godot 4 project (created in P0.05)
tools/                    art pipeline, casting builder, llm scripts, promptlab, bridge, steering tools
experiments/              the validated M0 experiments + results
data/casting.json         feeling → sprite/motion/voice/sound/music (generated by tools/casting)
art/leila/                final pixel sprites
assets/audio/             cue map, sources, licences (raw pool local-only)
production/               plan, tracker, briefs, handoffs, reviews, gates, journals
.claude/skills/           producer, tracker, protocol, 11 role playbooks, 5 review playbooks
```
Local-only artifacts live in the main tree `D:/lila` (models/, tools/llama/, assets/audio/_raw/). From a worktree, refer to them
by absolute path.
